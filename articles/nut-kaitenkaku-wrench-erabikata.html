溶融亜鉛めっき高力ボルトを、ナット回転角法で締める電動レンチを買いたい。でも同じ「トルシャット」でも型番が多く、希望小売価格は 54万円から 93万円です。候補は、「締めるボルトの径(M12〜M24)」「現場の電源(100V・200V・充電)」「締める場所の狭さ(ピストル型かコーナー型か)」の3つを、仕様欄の公表値に当てはめると絞れます。最後に、手持ちのソケットの形式(MRU・HRU・UR・差込角)が合うかを確かめます。

この記事は、TONE公式サイトの製品ページに載っている公表値を、そのまま並べて整理する記事です。当サイトが実機で締め比べた記事ではありません。比較はTONE 1社の7機種どうし(有線のトルシャット4機種とコードレストルシャット3機種)で、今回は TONE の公表値のみです。他社のナット回転角レンチは調べていません。締付け角度を何度にするか、締付けの合否をどう判定するかは扱いません。それは工具の公表値ではなく、設計・施工要領で決まることだからです。

先に結論
  • 型番は、まずボルト径で分かれます。M12 は TN12E-1T、M16・M20 は CTN200、M20・M22 は TN22E・TNC22・CTN220、M22・M24 は CTN240(いずれも高力 F8T。TN12E-1T だけ F10T)
  • 電源は3通りです。有線100V(TN12E-1T・TN22E-1T・TNC22-1T)、有線200V(TN22E-2T)、充電(CTN200・CTN220・CTN240)
  • 狭い所はコーナー型の TNC22-1T。公式の説明文に「全長158mmと軸方向に短く設計」とあります。角度は外付けの制御BOXで設定します
  • 締付角度設定範囲は TN12E-1T だけ 30〜240度、ほかは 90〜240度。角度精度は7機種とも ±10度です
  • 同じ M22 でも、付属のレバーソケットの形式が違います。MRUタイプ(TN22E・CTN220)、HRUタイプ(CTN240)、URタイプ(TNC22)。M22 に合わない CTN200 も MRUタイプです
  • 実売の目安は 38万円台から 70万円弱(価格.comの検索結果の最安値、2026-11-23 調査)。希望小売価格は 541,000円から 930,000円です

締付角度: 範囲は 90〜240度(TN12E-1T は 30〜240度)

角度の欄で違うのは、TN12E-1T の下限だけです。精度は7機種とも同じ値です。

  • 締付角度設定範囲は、TN12E-1T が 30〜240度、ほかの6機種が 90〜240度です。90度より小さい角度を設定する必要があるかどうかは、施工の側の条件で決まります
  • 角度精度は7機種とも ±10度です。この ±10度がどういう条件で測った値か(繰返しの精度か、絶対値か)は、製品ページに説明がありません。公式表記を確認できていないため記載しません
  • 角度の設定の仕方が、コーナー型だけ違います。ピストル型6機種は「本体内蔵の締付角度設定ダイヤル」、TNC22-1T は「外付け制御ＢＯＸの締付角度設定ダイヤル」です(いずれも公式の説明文)

締付け角度を何度にするかは、この記事では書きません。ボルトの種類・径・締める板の条件で決まる施工の値で、TONE の製品ページにも載っていません。設計・施工要領に従ってください。本締めの前の一次締めの工具は一次締めのトルクがばらつく|専用レンチの精度と適応径で並べています。

  • 特長欄に「アルミボディモータ」とあるのも TNC22-1T だけです

  • ピストル型6機種の全長は記載しません。仕様欄の「製品単体寸法 w・d・h」は、どの向きの寸法かの説明がページに無いためです。全長 158mm は TNC22-1T の説明文の値で、ほかの機種と同じ測り方の値かどうかは分かりません

選ぶ前の確認手順

上から順に
  1. 締めるボルトの種類・径と、回転角法で締めることを、設計図書と施工要領で確かめる
  2. 適応ボルトサイズの欄で候補を絞る。M12 は TN12E-1T、M16・M20 は CTN200、M20・M22 は TN22E・CTN220・TNC22-1T、M22・M24 は CTN240
  3. 現場の電源を見る。100V なら TN22E-1T(13.5A)・TNC22-1T(15A)、200V なら TN22E-2T(6.5A)、電源が取れなければ CTN 系
  4. 狭い所があるかを見る。軸方向に余裕が無ければコーナー型の TNC22-1T(全長158mm)
  5. 手持ちのレバーソケットの形式を確かめる。MRU・HRU・UR のどれか。足りない径のソケットはオプション品の欄で品番を探す
  6. 締付け角度の設定値は、設計・施工要領に従う。設定範囲(90〜240度、TN12E-1T は 30〜240度)に入るかだけを工具の側で確かめる

回転角法で締めない現場なら、別の工具の側です。トルシア形高力ボルトのようにピンテールを切って締付けを終えるボルトはシヤーレンチ(シャーレンチが入らない・切れない)、トルクを設定して締める六角ボルトは電動のナットランナー(ナットランナーでトルクが出ない・ばらつく)、電源も蓄電池も使えない場所で大きなトルクを掛けるなら手動の倍力レンチ(倍力レンチで大径ボルトが緩まない)があります。

この記事は工具の選び方に限っています。高力ボルトの締付けの手順・検査・合否の判定は、工事の仕様書や関係する基準で決まります。施工してよいかどうかは、仕様書と工事監理者に確認してください。

  • ボルト径で型番が分かれる。M12(TN12E-1T)、M16・M20(CTN200)、M20・M22(TN22E・CTN220・TNC22-1T)、M22・M24(CTN240)
  • 電源は有線100V・有線200V・充電の3通り。TN22E-1T と TN22E-2T は電圧だけが違う組
  • 狭い所はコーナー型の TNC22-1T(全長158mm、外付け制御BOXで角度設定)
  • 角度設定範囲は 90〜240度(TN12E-1T は 30〜240度)、角度精度は7機種とも ±10度。何度で締めるかは設計・施工要領に従う
  • 同じ M22 でも、付属のレバーソケットは MRU・HRU・UR で形式が違う
  • 実売の目安は 380,966円(TN12E-1T)から 699,637円(TNC22-1T)。候補が決まったら見積で確かめる
