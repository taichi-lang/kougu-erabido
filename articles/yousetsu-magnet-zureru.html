溶接マグネットで鉄の材料を立てたら、手を離したとたんに倒れた。位置を合わせたのに、マグネットを置くとき・外すときに材料が動いた。直角に当てたい場所に、マグネットの形が合わない。見るところは3つです。吸着力(N)がその材料に対して足りているか。保持したい角度がその機種にあるか。置くとき・外すときにずれるなら、磁力スイッチ付きか。

この記事は、スズキッド(スター電器製造)公式サイトの製品ページに載っている公表値を、そのまま並べて整理する記事です。実際に材料を保持して比べた記事ではありません。当サイトが実機で測った記録でもありません。比較はスズキッド1社の「マグホールド」シリーズどうしで、他社製品は入っていません。

先に結論
  • 吸着力の公表値は、機種で10倍以上違います。マグホールドS は 147N、スクエアV180 は 1800N です
  • 同じ 490N でも中身が違います。マグホールドL はスイッチなし、スイッチL はスイッチ付き、マルチL はスイッチ付きで角度が 15°〜210° です
  • 置くとき・外すときのずれは、公式がスイッチ式の説明で触れています。スイッチ式3機種の見出し文に「設置・取り外し時のズレも解消」とあります
  • 吸着力が大きい機種は、保持角度が 90° だけです。45°・135° が要るなら S・M・L、スイッチL、フォース。それ以外の角度ならマルチL です
  • 吸着力の測定条件は、製品ページにありません。この記事は N を「何kgの材料まで持てる」には言い換えていません

磁力スイッチ: 置くとき・外すときのずれ

位置を合わせたあと、マグネットを当てる瞬間や外す瞬間に材料が動く。この困りごとには、公式がスイッチ式の説明で触れています。スイッチL(P-735)・フォース(P-738)・マルチL(P-745)の見出し文に、磁力ON/OFFのスイッチ付きで「設置・取り外し時のズレも解消」とあります(スズキッド公式)。

  • スイッチ式の特徴欄 — スイッチでワークへの取付・取外しが手軽になる、使っていない時に鉄粉が付く心配もない、という内容です(P-735・P-738・P-745)
  • スクエアV90・V180 — スイッチを切り替えて磁力のON/OFFができる、とあります
  • S・M・L — 製品ページに磁力スイッチの欄がありません。中央の穴にドライバー等を差し込めば手軽に移動できる、と書かれています

同じ 490N の L(P-733)とスイッチL(P-735)は、どちらもフェライトで、保持角度も 45°・90°・135° で同じです。仕様表で違うのは、磁力スイッチの有無、奥行(23mm と 39mm)、質量(860g と 820g)です。

スイッチをOFFにしたとき磁力がどこまで下がるか(完全に無くなるのか)は、公式表記を確認できていないため記載しません。スイッチの操作に要る力も公表されていません。

磁石以外の固定方法

溶接マグネットが吸い付くのは、磁石に付く材料だけです。材料の重さや形が合わないときは、固定のしかたを変える選択肢もあります。

  • ねじで締めて押さえる道具はクランプがずれる・外れるで、最大締付力と首振り角度の公表値を並べています
  • 握ってロックする道具はバイスプライヤが滑る・外れるで、口の形と口開きの差を扱っています

どの固定方法が向くかは、材料の形・重さ・求める精度で変わります。当サイトは固定の強さを比べていません。

固定ではなく溶接そのもののトラブルは、別の記事にまとめています。薄い板に穴があくときは半自動溶接で薄板に穴があく原因、ワイヤが送られないときは半自動溶接機のワイヤが出ない、被覆アーク溶接で棒が母材に付くときは溶接棒がくっつく原因です。溶接機が途中で止まるときは100V溶接機の定格使用率を見てください。

ずれる・倒れるときの確認手順

上から順に
  1. いま使っている機種の吸着力(N)と磁石の種類を、仕様表で確かめる
  2. 手を離すと動くなら、吸着力の大きい機種があるかを見る。S 147N → M 245N → L 490N。それ以上はネオジムの機種
  3. 保持したい角度が、その機種の保持角度にあるかを見る。900N 以上の3機種は 90° だけ
  4. 置くとき・外すときに動くなら、磁力スイッチ付きかを見る。S・M・L にはスイッチの欄が無い
  5. 丸棒・パイプなら、溝のある型かを見る。スクエアV90・V180 の特徴欄に記載がある
  6. それでも合わないときは、クランプなど別の固定方法を検討するか、メーカーか販売店に相談する

溶接は、強い光・火花・高温の金属・煙が出る作業です。この記事は溶接マグネットの取扱説明書やパッケージの注意書きを読んでおらず、作業の手順は書いていません。使う前に、溶接機とマグネットそれぞれの注意書きを確認し、それに従ってください。溶接用の遮光面の仕組みは自動遮光溶接面が暗くならないにあります。
