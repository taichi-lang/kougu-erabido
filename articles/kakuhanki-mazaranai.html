かくはん機を回しているのに、モルタルが容器の底に残る。塗料が飛び散る。重い材料で途中から回転が落ちる。ダマが残る。この記事は、そうした場面で回転数・スクリュ(羽根)の大きさ・モーターの粘り・材料の入れ方のどこに原因があるのかを切り分け、必要ならかくはん機やスクリュを選び直すためのものです。

比較に使うのは、HiKOKI(工機ホールディングス)の公式サイトに載っているかくはん機3機種です。同一メーカー内の比較で、他社の機種は今回扱いません。HiKOKI の AC機2機種は、どちらも消費電力 740W・電流 7.8Aと同じ値なのに、UM22V(低速高トルク形)は 0〜550min⁻¹・スクリュ径 220mm、UM15V は 0〜1,200min⁻¹・スクリュ径 150mmと、回転数が約2倍違い、羽根の大きさも違います。コードレスの UM36DA は、この2つを1台で切り替える機種です。

先に結論
  • モルタルなど重い材料は「低速・大径」。公式の公表値では UM22V が 0〜550min⁻¹・スクリュ径 220mm
  • 塗料など軽い材料は「高速」。UM15V が 0〜1,200min⁻¹・スクリュ径 150mm
  • 両方を混ぜるなら2段切替。UM36DA は公式に「高粘度(モルタル)0〜500min⁻¹ モード1(低速)」「低粘度(塗料、レベラー)0〜1,200min⁻¹ モード2(高速)」と、材料と回転数の対応を書いている
  • 飛び散るなら、回し始めの速さを見る。AC機2機種は無段変速で、公式に「材料のはね返りを軽減」とある
  • 配合・水量は、材料メーカーの施工資料に従う。道具を替えても、材料の条件が違えば混ざり方は変わる

混ざらない原因を切り分ける

「かくはん機で混ざらない」には、底に残る・飛び散る・回転が落ちる・ダマが残るの4つの場面が混ざっています。場面ごとに疑う所が違うので、先に分けます。

症状疑う項目確かめること
モルタルが容器の底や隅に残る容器・材料の量に対してスクリュが小さい(一般論)スクリュの外径と容器の大きさ。羽根が底まで届いているか
塗料・水っぽい材料が飛び散る材料の粘度に対して回転が速すぎる・回し始めが急(一般論)変速ダイヤルの位置。スイッチの引き始めをゆっくりにできるか
重い材料で回転が落ちる・止まりそうになる高粘度の材料にモーターが負けている(一般論)機種が高粘度向けか。電源と延長コード(AC機)、バッテリの残量(充電式)
ダマが残る加水量・投入の順番(一般論)材料メーカーの施工資料にある水量と手順

この記事の前半は「なぜ混ざらないか」に答えます。後半は、材料の重さと作業の量から、機種とスクリュをどう選ぶかを扱います。モルタルやセメント、塗料の配合・水量・練り時間は扱いません。数値は材料ごとに違うので、材料メーカーの施工資料と各製品の取扱説明書に従ってください。

回転数が材料に合っていない — 低速と高速

一般に、モルタルのような粘りの強い材料は、速く回すより、ゆっくり大きく回して全体を動かすほうが向くとされます。逆に、塗料のような粘りの弱い材料は、速めに回して混ぜる、というのが一般的な説明です。

HiKOKI のかくはん機3機種は、この「回転数」の公表値がはっきり分かれています。

この表で目を引くのは、UM22V と UM15V の消費電力が同じ 740Wだということです。同じ電力で、UM22V は回転を半分以下に抑えて大きな羽根を回し、UM15V は速く回して小さめの羽根を回す、という作りの違いになっています。UM22V に「低速高トルク形」と名前が付いているのはこのためで、重い材料を相手にする機種だと読めます。

材料と回転数の対応を、メーカー自身がはっきり書いているのは UM36DA です。公式の製品ページには、シフトレバーで切り替える2つのモードについて「高粘度(モルタル)0〜500min⁻¹ モード1(低速)」「低粘度(塗料、レベラー)0〜1,200min⁻¹ モード2(高速)」とあります。UM22V の 0〜550min⁻¹ と UM15V の 0〜1,200min⁻¹ に近い2つの速さを、1台で持っている形です。

ただし、材料ごとに何min⁻¹で回せばよいか、という一般的な目安は HiKOKI の公式には書かれていません。公式から言えるのは「モルタル＝低速側、塗料・レベラー＝高速側」という UM36DA の対応までです。この記事でも、材料ごとの回転数の目安は作りません。

底に残る — スクリュの大きさと形

底や隅に材料が残る場合は、容器や材料の量に対して羽根が小さいことを疑います。一般に、羽根の外径が大きいほど一度に動かせる範囲は広くなる、というのが一般的な説明です。ただし、HiKOKI の UM22V・UM15V の仕様表には1回に混ぜられる量(kgやL)の記載はありません。量の目安は書きません。

見るべき数値は、仕様表の「能力(スクリュ径)」と、本体に取り付けるスクリュの外径です。この2つは同じとは限りません。

UM36DA は注意が要ります。仕様表の能力は 200mm ですが、標準付属のスクリュ(A5)の外径は 150mmです。公式の別売部品の一覧に載っているスクリュの外径は 115〜180mm で、200mm のスクリュは一覧に見当たりませんでした。能力の数字だけを見て「200mmの羽根が付いてくる」と思わないようにしてください。標準付属の A5 について、公式は「鋼材製スクリュ」として「塗料もモルタルもかくはんできます。」と書いています。

缶の隅に残る塗料には、UM15V の製品ページに別売の「隅ペラ」(長さ650mm・最大幅127mm・オールステンレス製・税別¥22,000)が載っていて、公式に「缶の隅までよく混ざる」「容器を傷つけにくいスクリュ形状」とあります。UM36DA の別売部品にも同じコードNo.の「隅ぺら(シャフト一体型)」が載っていて、こちらには「※モルタルなどの高粘度材料には適しません。」と注記があります。隅ペラは塗料など軽い材料の側の道具、ということです。

飛び散る — 回し始めの速さ

塗料など水っぽい材料が飛び散るのは、一般に、回し始めから速く回しすぎることが原因の一つとされます。羽根を材料に沈めてからゆっくり回し始める、というのが一般的な扱い方です。

HiKOKI の AC機2機種は、どちらもこの「回し始め」に触れています。UM22V は「ダイヤル付無段変速スイッチで回転速度が調整可能」「スロースタートで材料のはね返りを軽減します。」、UM15V は「無段変速スイッチ採用でかくはん速度が調整可能」「かくはん開始時の材料のはね返りを軽減し、材料に適したかくはん速度に調整することが可能です。」と書いています。どちらも変速ダイヤル付きで、スイッチの引き量を調整できるとあります。

UM36DA は、シフトレバーで低速・高速のモードを選ぶ形です。軽い材料でも、飛び散るなら速いモードのまま回し始めない、というのが道具の側でできる工夫になります。UM36DA の製品ページには、スロースタートに当たる記載は見当たりませんでした。記載が見当たらないことは「その機能が無い」と同じ意味ではないので、取扱説明書で確かめてください。UM36DA には本体へのかくはん材の付着を防ぐ「ラバーシールド」と、電池接続部への付着を防ぐ「バッテリーカバー」の記載があります。

塗料を混ぜたあと吹き付けで塗る場合、吹けない原因は別にあります。スプレーガンが吹けない原因を参照してください。

回転が落ちる — 高粘度と電源

モルタルなど重い材料で回転が落ちる、止まりそうになるのは、一般に、材料の抵抗にモーターが負けている状態です。対策は、高粘度向けの機種(低速高トルク形)を選ぶこと、そして電源の側で電圧を落とさないことです。

コードレスの UM36DA について、HiKOKI は「定速度制御により高負荷でも回転が落ちにくく高粘度材料も速く混ぜられる」と書いています。製品ページには AC品とのかくはんスピードの比較(材料：モルタル、押付荷重30N時、当社調べ)も載っていますが、数値はグラフの画像で、テキストで読める形では公表されていないため、この記事では倍率を書きません。メーカーは「数値は参考値です(材料や条件により異なります)」と注記しています。

AC機の UM22V・UM15V は電流 7.8A です。延長コードやコードリールを使う場合、細いコードを長く伸ばすと電圧が落ち、工具の力が出にくくなる、というのが一般的な説明です。電動工具の延長コードの太さと長さの上限は電動工具の延長コードは何mまで伸ばせるか、コードリールを巻いたまま使うときの電流の上限はコードリールの定格電流と限度電流で扱っています。

ダマが残る — 加水量と投入の順番

ダマ(混ざりきらない粉の固まり)が残る場合は、道具より先に材料の側を疑います。一般に、水の量や、粉と水をどちらから入れるかの順番で混ざり方が変わる、とされます。ただし、正しい水量・投入順・練り時間は材料ごとに違い、材料メーカーが施工資料で指定しています。この記事では数値を断定しません。袋や缶の表示、材料メーカーの施工資料に従ってください。

道具の側で確かめられるのは、ここまでの3点です。回転数が材料に合っているか、羽根が容器の底と隅まで動かせているか、重い材料で回転が落ちていないか。このどれにも当てはまらないのにダマが残るなら、材料の条件を見直すのが先です。

買う前の確認手順

この順で確認する
  • 材料を決める。モルタル・壁材など重い材料か、塗料・レベラーなど軽い材料か、両方か
  • 回転数を決める。重い材料は低速側(UM22V・UM36DA モード1)、軽い材料は高速側(UM15V・UM36DA モード2)
  • スクリュを決める。能力(スクリュ径)と、標準付属のスクリュの外径は同じとは限らない。材料別の別売スクリュも見る
  • 電源を決める。AC機なら延長コードの太さ。充電式なら使える蓄電池の型番と1充電当たりの作業量
  • 材料の条件を確かめる。水量・投入順・練り時間は材料メーカーの施工資料に従う

左官・内装・塗装の現場で、かくはん機やスクリュ、蓄電池をまとめてそろえる場合は、この記事の下の見積依頼から、型番が決まっていなくても用途と数量で見積を取れます。
