「テーパピン 呼び径」で調べると、関連する検索は「テーパーピン 規格 表」「ネジ付きテーパーピン 規格」「テーパーピン 下穴 規格」「テーパーピン長さ選定」で埋まり、関連する質問には「テーパーピンのA種とB種の違いは?」が並びます。

この「A種とB種」は、多くの場合精度の等級だと受け取られています。規格の本文はそう書いていません。

そして厄介なことに、A種・B種という同じ言葉が、テーパピンでは2つの別の規格に出てきて、意味が違います。

この記事は、JIS B 1352「テーパピン」と JIS B 1358「ねじ付きテーパピン」の原文を読み、記号と区分が規格上どこまでを決めているかを整理する記事です。当サイトがピンを打ち込んで確かめた記録ではありません。

先に結論
  • JIS B 1352 の A種・B種は「テーパ部の表面粗さ」による区分です。規格の箇条2 は「ピンの種類は，テーパ部の表面粗さによって区分し」と書いています。硬さでも寸法精度でもありません
  • その表の備考は「主として研削によるもの」(A種)・「主として旋削によるもの」(B種)です。つまり作り方の違いが表面粗さの違いとして書かれています
  • 1級・2級は、本体ではなく附属書の区分です。しかも軸が違い、「テーパの許容差によって」1級・2級に区分すると書かれています。A種/B種(粗さ)と1級/2級(テーパ許容差)は、別の物差しです
  • その附属書には「なお，この附属書は，将来廃止する。」と書かれています。さらに「国際性確保のため，ピンの形状・寸法，テーパ精度及びテーパ部の表面粗さは，本体の規定によるのがよい。」とも書かれています
  • JIS B 1358(ねじ付きテーパピン)にも A種・B種があります。ただし意味が違います。こちらは3種類で、A種・B種は「めねじ付きテーパピン」の中だけの区分です。おねじ付きテーパピンには A種・B種がありません
  • 表面粗さの数値が本文の文字で書かれているのは、B 1352 ではなく B 1358 のほうです(注(1)に Ra=0.8μm は主として研削、Ra=3.2μm は主として旋削)
  • JIS B 1352:2006 は「追補1」です。まえがきに「JIS B 1352：1988は改正され，一部が置き換えられた。」とあり、本文の柱は「B 1352-1988」のままです。置き換えの指示は8か所で、寸法の付表そのものは1つも書き換えられていません
  • その追補の後に、さらに正誤表があります。作成日は平成20年9月1日、訂正箇所の区分は「附属書」の「付表」です
  • 呼び径は「小端側の径」です。付表の備考2 が「小端側の径 (d) に対して」と書いています。既定の許容差は h10 ですが、「h10以外の許容差を必要とする場合は，注文者が指定する。」とも書かれています
  • ⚠ この記事に呼び径・長さ・硬さの数値表はありません。当サイトが読んだ本文ページでは、付表と硬さの表の数値部分が画像で置かれており、1つも確定できませんでした

A種・B種は何で分かれているのか

JIS B 1352 の箇条2「種類」は、区分の軸を1行で書いています。

「ピンの種類は，テーパ部の表面粗さによって区分し，表1の2種類とする。」

そして表1 の備考が、その2つに次の説明を付けています。

種類規格の表1 が付けている備考
A種主として研削によるもの。
B種主として旋削によるもの。

分かれているのはテーパ部の表面粗さで、備考が示しているのは加工方法です。注(1)は「Raは，JIS B 0601(表面粗さの定義と表示)に規定する中心線平均粗さによる。」と書いています。

⚠ A種・B種それぞれの Ra の数値は、この記事に書いていません。その数値は表1 の中にあり、当サイトが読んだページでは表の数値部分が画像だったため確定できていません。

⚠ 硬さも A種・B種では分かれていません。硬さは箇条3 の別の表(表2)にあり、そちらの区分は「熱処理しないもの」「焼入焼戻しを施したもの」「ステンレスピン」です。種類とは別の軸です。

1級・2級は本体になく、附属書にある

「テーパピンの等級」を探すと 1級・2級 という言葉が出てきます。これは本体の区分ではありません。

附属書の箇条2 が「ピンの等級は，テーパの許容差によって，1級及び2級に区分する。」と書いています。本体の A種/B種は表面粗さ、附属書の1級/2級はテーパの許容差で、物差しが違います。

附属書の位置づけも、附属書自身が書いています。

附属書が自分について書いていること書かれている場所
表題は「ISO 2339によらないテーパピン」附属書の見出し
「この附属書で規定するピンは，JIS B 1352-1975(テーパピン)に準拠したものである」附属書 1. の備考
「国際性確保のため，ピンの形状・寸法，テーパ精度及びテーパ部の表面粗さは，本体の規定によるのがよい。」同上
「なお，この附属書は，将来廃止する。」同上

つまり「旧JIS」と呼ばれているものは、規格の外にあるのではなく、同じ規格の附属書として中に入っています。そしてその附属書自身が、本体によるほうがよいと書いています。

本体が何に基づいているかも備考にあります。「この規格の本体は，あみかけを施した部分を除き ISO 2339-1986 (Taper pins, unhardened) によっている。」、そして「ピンの形状・寸法，テーパ精度及び表面粗さが ISO 2339 によらないものは，附属書に規定する。」です。

表面粗さの数値だけは、附属書の側に文字で書かれている

附属書の箇条5「外観」には、粗さが本文の文字として書かれています。ここは表ではないので読み取れます。

そしてこの1文は、2006年の追補で書き換えられた箇所でもあります。

等級1988年の本文2006年の追補による置き換え後
1級3.2S最大高さ粗さ RZ3.2
2級6.3SRZ6.3

数字そのものは変わっていませんが、根拠にしている規格とパラメータの種類が変わっています。1988年の側は JIS B 0601「表面粗さの定義と表示」、追補後は JIS B 0601「製品の幾何特性仕様(GPS)−表面性状:輪郭曲線方式−用語，定義及び表面性状パラメータ」の最大高さ粗さです。

⚠ 「3.2S と RZ3.2 が同じ意味か」は書いていません。当サイトは JIS B 0601 の本文を読んでいないので、換算の可否について何も述べていません。書いたのは、追補がそう置き換えたという事実だけです。

JIS B 1352:2006 は追補で、寸法の付表は1988年のまま

「2006年版」と書かれていると、寸法が新しくなったように見えます。当サイトが読んだ限りでは、そうではありません。

2006年版のまえがきは「この追補は，(中略)これによって，JIS B 1352：1988は改正され，一部が置き換えられた。」と書いており、標題も「テーパピン(追補1)」です。中身は「JIS B 1352:1988を，次のように改正する。」で始まる置き換えの指示だけです。

#置き換えの指示があった場所何が置き換わったか
1箇条2(種類)の注(1)引用する JIS B 0601 が新しい表題のものへ(附属書2)
28.1(硬さ検査)JIS Z 2244 / Z 2245 の規格名の表記
3付表の注(10)JIS B 0401 → JIS B 0401-2
4付表の備考2JIS B 0401 → JIS B 0401-2
5附属書 箇条5(外観)3.2S / 6.3S → RZ3.2 / RZ6.3
6附属書付表図の置き換え
7附属書付表の備考2JIS B 0031 が新しい表題のものへ
8引用規格上記5規格の表題を一括で置き換え

8か所のうち、寸法の数値そのものを書き換えたものは1つもありません。変わったのは引用先の規格の名前・番号と、粗さの表記と、附属書の図です。

したがって、種類(A種・B種)・硬さの区分・材料・呼び方は、1988年の本文がそのまま生きています。

⚠ 当サイトが読んだページは、表題が「JIS B 1352 : 2006 テーパピン」で、本文の柱が「B 1352-1988」でした。両方の年が同じ資料に現れます。これは追補という形式によるものですが、「現行の版は何年か」を当サイトは断定していません。

さらに正誤表がある。訂正されたのは附属書の付表

同じ 2006年版の資料には、追補の本文とは別に正誤表が付いています。

  • 見出しは「JIS B 1352:2006 テーパピン(追補1) 正誤」
  • 作成日は「平成20年9月1日作成」
  • 訂正箇所の区分は「附属書」、位置は「付表」

⚠ 「誤」と「正」の中身は書いていません。当サイトが読んだページではその部分が画像で置かれており、確定できませんでした。書けるのは「附属書の付表に訂正がある」までです。

版を確かめるときは、追補だけでなく正誤表の有無まで見る必要がある、という例です。

ねじ付きテーパピン(JIS B 1358)の A種・B種は、別の意味である

ここが、この記事でいちばん取り違えやすい箇所です。

JIS B 1358 の箇条2 は「ピンの種類は，ねじの種類及びテーパ部の表面粗さによって区分し，表1の3種類とする。」と書いています。2種類ではなく3種類で、区分の軸が「ねじの種類」と「表面粗さ」の2つあります。

規格区分の名前何で分けているかいくつあるか
JIS B 1352
テーパピン		A種・B種(本体)テーパ部の表面粗さ2種類
1級・2級(附属書)テーパの許容差2等級
JIS B 1358
ねじ付きテーパピン		めねじ付き A種・B種ねじの種類(めねじ)+ 表面粗さ合わせて3種類

おねじ付きテーパピンに A種・B種はありません。表1 の備考も、めねじ付きの2つには「ISO 8736のType Aによるもの」「ISO 8736のType Bによるもの」、おねじ付きには「ISO 8737によるもの」と、対応する国際規格の番号が別であることを書いています。

そして粗さの数値は、こちらの規格では本文の文字で書かれています。注(1)に「なお，Ra＝0.8μmは，主として研削によるもの，Ra＝3.2μmは，主として旋削によるものである。」とあります。

⚠ この Ra の数値は JIS B 1358 の注(1)の記載です。当サイトはこれを JIS B 1352 の A種・B種の数値としては書いていません。B 1352 側の数値は表の中(画像)にあり、確定できていないためです。

硬さの区分も違います。B 1358 の表2 は、めねじ付き(A種・B種)が「施さないもの」、おねじ付きが「焼入焼戻しを施したもの」と、種類そのものに熱処理が結び付いています。

ねじの等級は 6H と 6g。「当分の間，2級を用いてもよい」

JIS B 1358 の箇条5「ねじ」は、ねじの規格と等級を指定しています。

種類ねじの種類等級
めねじ付きテーパピン(A種・B種)JIS B 0205(メートル並目ねじ)本体のめねじJIS B 0209 本体の 6H
ただし当分の間 JIS B 0209 附属書1の2級を用いてもよい
おねじ付きテーパピンJIS B 0205 本体のおねじJIS B 0209 本体の 6g
ただし当分の間 JIS B 0209 附属書1の2級を用いてもよい

「当分の間，2級を用いてもよい」が両方に付いています。つまり同じ呼びのピンでも、ねじの等級が6H/6gと2級のどちらかでありうると規格自身が認めています。

そして2級を適用した場合は、それを指定事項として示すと注(6)に書かれています。指定事項に何も書かれていなければ、どちらであるかは呼び方からは分かりません。

呼び方に何を書くかが、規格ごとに違う

買うときに指定する項目そのものが、3つの規格で揃っていません。

JIS B 1352 本体JIS B 1352 附属書JIS B 1358

B 1352 の A種は「A」、B種は「B」としてもよいと注(4)にあります。材料の書き方も両規格で共通で、熱処理しない鋼ピンは St の記号でもよく、焼入焼戻しを施したものは材料記号の後に Q を付けると書かれています。

包装の表示にも「種類」または「等級」が入ります。B 1352 本体は名称・種類・呼び径×呼び長さ・材料・数量・指定事項・製造業者名、附属書は規格名称・等級・… という並びです。

材料は、規格が「原則として」の形で決めている

材料は表になっていますが、こちらは本文の文字として読み取れました。

箇条6 の書き出しは「ピンの熱処理及び材料は，原則として表3による。」です。「原則として」が付いており、注(3)には「調質鋼を用いた場合は，焼入焼戻しを省略してよい。」とあります。

⚠ 「S 43 C〜」の上限は書いていません。当サイトが読んだページではその行が途中で切れており、上限側の記号を確定できませんでした。JIS B 1358 の同じ位置には「S 43 C〜S 45 C」と書かれていますが、それを B 1352 の値として転記はしていません。

表面処理については「ピンの表面処理は，一般に施さない。ただし，鋼ピンの場合は，供給時にさび止め油を塗布する。」と書かれています。めっきが必要なら注文者が指定する形です。

買う前に確認すること

確認の順番
  • ① ねじが要るかどうかを先に決める。ねじが要るなら規格番号が変わります(B 1352 → B 1358)
  • ② ねじが要る場合、めねじ付きかおねじ付きかで種類が決まります。抜くためのねじ穴が要るのか、ナットで締めたいのかで別物です
  • ③ A種・B種と書かれていたら、どちらの規格の A種・B種かを見る。B 1358 ではめねじ付きにしか付きません
  • ④ A種・B種は表面粗さの区分です。硬さは別の表、テーパの許容差は附属書の1級・2級で、いずれも別の軸です
  • ⑤ 1級・2級と書かれていたら、附属書側の呼びです。附属書には「将来廃止する」「本体の規定によるのがよい」と書かれています
  • ⑥ 呼び径は小端側(細いほう)の径です。大端側で測ると呼びと合いません
  • ⑦ 公差の既定は h10 です。それ以外が要る場合は注文者が指定する形で、B 1358 では呼び径の後に書きます(例 10 f 8×85)
  • ⑧ ねじの等級は 6H / 6g が本体ですが、「当分の間，2級を用いてもよい」と書かれています。2級なら指定事項に示される決まりです
  • ⑨ 版を確かめるときは、追補と正誤表の両方を見る。2006年は追補で、その後 平成20年9月1日付の正誤表があります
  • ⑩ 寸法・硬さ・粗さの数値は、規格の表そのもので確かめる。当サイトはそれらの数値表を掲載していません

同じ「ピン」でも平行側は別番号です。公差の記号がどこまで規格の決めごとかは平行ピン(ノックピン)の公差は「h7」ではない — JIS B 1354が定めているのは m6 と h8 の2つにまとめました。そちらは公差域クラスで分かれ、この記事のテーパピンは表面粗さで分かれています。同じピンでも区分の軸が違います。

割りピンの呼び径が何を指しているかは割りピンの「呼び径」は穴の径であってピンの太さではない(JIS B 1351)にあります。この記事の「呼び径は小端側の径」と同じで、呼びの数字が何の寸法かは規格ごとに違います。

「2000年代の版が追補で、寸法は昔のまま」という形は、この記事だけのものではありません。実際に数えた例がキー溝の「JIS B 1301:2009」は追補で、寸法は1996年のままにあります。そちらは置き換えが3か所、この記事は8か所です。

附属書が「将来廃止する」と自分で書いている例は管用ねじの R・Rc・Rp・G は「テーパか平行か」だけでは決まらないにもあります。そちらの附属書は「次回改正時に廃止年限を明らかにする」で、この記事の附属書は「将来廃止する」です。文言が違います。

記号が同じ文字でも規格が違えば別物である、という点はOリングのPとGは「太さの系列」ではなく用途の区分(JIS B 2401-1)と同じ形です。この記事の A種・B種が2つの規格で意味が違うのも、同じ理由によります。

呼び番号のどこまでを規格が決めているかはベアリングの型番は、途中までしかJISが決めていない(JIS B 1513)、軸まわりの別の部品はキー及びキー溝と止め輪の呼びは軸径ではない(JIS B 2804)を参照してください。

穴をあける側の話はタップの下穴径(JIS B 1004)にあります。ただしテーパピン用の下穴(テーパリーマ)については、当サイトはその規格の本文を読んでいないので何も書いていません。

本体に何が表示されるか・表示されないかという系統はいもねじは「本体に何も表示しない」と規格が決めている(JIS B 1177)と本体表示だけでは分からないものにあります。この記事の「指定事項に書かれていなければ、ねじの等級は呼び方から分からない」も同じ系統です。

情報の根拠
