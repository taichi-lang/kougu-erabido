接地抵抗計(アーステスタ)で接地抵抗が測れない、OKランプが点かない、補助接地棒を打てる場所がないという相談は、まずその現場で使える測定方式と、手元の機種の測定方式が合っているかから確かめます。接地抵抗計には、補助接地棒を2本打って測る精密測定(3極法)、補助接地棒を使わない簡易測定(2極法)、接地線をはさんで測るクランプ式があり、機種によって使える方式が違います。

この記事は、共立電気計器公式サイトの製品ページと「よくある質問」に載っている内容を、そのまま並べて整理する記事です。実際に接地抵抗を測った記事ではありません。比較は今回は共立電気計器の公表値のみで、他社の接地抵抗計は入っていません。取扱説明書は今回読んでいません。そのため、補助接地棒を打つ位置や間隔、2極法で基準にする接地の条件など、測り方の手順はこの記事では扱いません。A種〜D種の接地抵抗の基準値もこの記事では書きません。種別ごとの基準値は、法令と電気工事業者に確認してください。

先に結論
  • 補助接地棒を打てない場所では、3極法(精密測定)は使えません。簡易測定(2極法)に対応した機種か、クランプ式を検討します。KEW 4300 は製品ページで「接地棒のいらない簡易測定専用」と説明されています
  • クランプ式の MODEL 4200 は、製品ページに「単独接地の測定はできません」と書かれています。測定できるのは「多重・共用・構造体接地」です
  • OKランプが点かないとき、共立のよくある質問が挙げている確認項目は4つ。測定コードの本体への装着、補助接地棒へのコードの装着、補助接地棒の水分、測定コードの断線です
  • 補助接地抵抗の許容範囲がレンジごとに公表されているのは、今回の5機種では KEW 4105DL だけです(10kΩ/50kΩ/100kΩ以内)。MODEL 4102A は「警告機能付き(LEDで警告)」の記載で、数値は製品ページにありません
  • マルチメータ(テスター)の抵抗レンジでは、接地抵抗は測れません。共立のよくある質問に「地電圧等の影響を受けるため」と書かれています
  • メーカー希望小売価格(税込)は 41,800円(4300)〜134,200円(4200)。3極法と2極法の両方を使えるのは 4102A・4105DL・6022 の3機種です

原因1: 補助接地棒を打てない場所で、3極法の機種を使おうとしている

精密測定(3極法)は、補助接地棒を地面に打ち、測定コードで本体とつないで測る方式です。舗装された場所や屋内など、補助接地棒を打てない場所では、この方式は使えません。5機種の測定方式は次のとおりです。

原因2: 補助接地棒とコードの状態(OKランプが点かない)

共立電気計器の「よくある質問」には「接地抵抗測定時にOKランプが点灯しない」という項目があり、確認することとして次の4つが挙げられています(機種名の指定はありません、2026-11-26 確認)。

  • 測定コードが本体に確実に装着されているか
  • 補助接地棒に測定コードが確実に装着されているか
  • 補助接地棒の水分が十分か(十分に水分を与える)
  • 測定コードに断線がないか(抵抗レンジにしてリード線を短絡させて調べ、断線していれば交換する)

補助接地棒が地面とどれだけ通じているか(補助接地抵抗)によって、測れる範囲が決まっている機種があります。

  • KEW 4105DL は、補助接地抵抗の許容範囲が 20Ωレンジで 10kΩ以内、200Ωで 50kΩ以内、2000Ωで 100kΩ以内と公表されています。許容範囲内の確度は ±5%rdg±10dgt で、通常の確度(±1.5%rdg±0.08Ω など)は「精密測定の場合、補助接地抵抗は100Ω±5%以下の条件」と注記されています
  • MODEL 4102A は、特長欄に「補助接地電極の抵抗の影響が確認できる警告機能付き(LEDで警告)」「補助接地電極の抵抗が大きくても測定誤差が出にくい」とあります。許容範囲の数値は製品ページに無く、公式表記を確認できていないため記載しません
  • KEW 6022 は、特長欄に警告機能の例として「補助接地OK」が挙げられています。どの条件で点くかは製品ページに書かれていないため記載しません
  • 付属の測定コードの長さは、4102A が 赤20m・黄10m・緑5m、4105DL がコードリールの赤20m・黄10m と緑5mです。コードの長さが補助接地棒を打つ位置にどう関係するかは、取扱説明書を読んでいないため書きません

なお、同じよくある質問には「接地抵抗レンジで、プローブコネクタを装着していなくても測定スイッチを押すと動作ランプが点灯しメーターが振り切れる」という項目もあり、回答は「故障ではありません」「内部ショートにより動作します」です。

原因3: クランプ式を単独接地に当てている

MODEL 4200 は、接地線をクランプするだけで接地抵抗を測る機種です。補助接地棒は使いません。ただし製品ページには、次の注意書きがあります。

  • 「多重・共用・構造体接地で測定可能であり、単独接地の測定はできませんので、ご注意ください。」
  • 被測定導体径は最大約φ32mm。これより太い接地線ははさめません
  • 接地抵抗の測定範囲は 20.00/200.0/1500Ω(オートレンジ)。600〜1580Ωは「表示のみ確度保証外」です。応答時間は接地抵抗で約7秒です
  • 接地抵抗のほか、1mA〜30Aの漏れ電流と交流電流を測れます(真の実効値表示)

測ろうとしている接地が単独接地なら、MODEL 4200 では測れません。その場合は、補助接地棒を打てるなら3極法の機種(4102A・4105DL・6022 に別売コード)、打てないなら2極法の機種を検討します。どの接地が単独接地にあたるかの判断は、設備の図面と電気工事業者に確認してください。

原因4: 地電圧・ノイズ・活線

接地抵抗計には、接地にかかっている電圧(地電圧)を測る機能や、電圧があると警告する機能がある機種があります。公表されている内容は機種ごとに違います。

  • MODEL 4102A: 接地電圧(50/60Hz)0〜30V(AC)を測定。特長欄に「地電圧測定も可能」
  • KEW 4105DL: 電圧計 AC0.0〜300.0V・DC±0.0〜±300.0V。特長欄に「ノイズに強い！地電圧25Vまで測定可能」
  • KEW 4300: 「30V以上の電圧検知で活線警告(測定ボタンを押すまで地電圧を測定)」
  • MODEL 4200: 「接地抵抗測定時に影響を及ぼす電流を自動検出し、ノイズマークを表示するノイズチェック機能」

値が安定しない原因を並べた公式の説明は、今回確認できていません。上の機能があることは公表されていますが、どの程度の地電圧やノイズで値がどれだけ変わるかの数値は製品ページに無く、作った数値は載せません。

KEW 4300 の特長欄には「微小測定電流(最大2mA)でELBの動作を防ぐ」とあります。ELB は漏電遮断器のことです。これは製品ページの文言の引用で、どの漏電遮断器・どの条件でも動作しないという意味かは製品ページに書かれていないため、この記事では言い切りません。

電圧があるかどうかを先に確かめる道具については、検電器が反応しない原因で、検電器の電圧範囲と AC/DC の違いを整理しています。

原因5: テスター(マルチメータ)で測ろうとしている

共立電気計器のよくある質問には「接地抵抗は測定できますか?」という項目があり、回答は「地電圧等の影響を受けるため、マルチメータの抵抗レンジでは接地抵抗の測定は出来ません」です(2026-11-26 確認)。接地抵抗は、接地抵抗計で測ります。

テスターで測れるもの・測れないものの違いは、テスターで電流が測れない原因でも、電流レンジとヒューズの公表値から整理しています。

接地抵抗計が必要になる場面と、電源まわりの記事

  • 業務用の200V機器を新しく入れるときは、電源と接地の工事を電気工事業者に頼む場面があります。単相・3相200Vの機器の見分け方は業務用電気ヒーターが使えない原因にあります
  • 発電機やトランス、コードリールから電動工具を動かす場合の電源側の見方は、発電機で電動工具が動かない原因、トランスで工具が動かない原因、コードリールの定格電流と限度電流で、メーカーの公表値から整理しています。これらの機器の接地のしかたは、この記事では扱いません

型番が決まっていなくても、この記事の下の見積依頼から、測りたい接地の種類(単独接地か、多重・共用・構造体接地か)、補助接地棒を打てる地面があるかどうか、測る場所の数、絶縁抵抗の測定もあわせて必要かどうかを書いて送れば、見積を取れます。別売の測定コードやケースをあわせて手配する場合は、型番(例: 7241A、7245A)も書いてもらえると見積が1回で済みます。

選ぶ前の確認手順

上から順に
  1. 測りたい接地が、単独接地か、多重・共用・構造体接地かを確かめる。単独接地なら、クランプ式の MODEL 4200 は使えない
  2. 補助接地棒を打てる地面があるかを見る。打てるなら3極法の機種(4102A・4105DL、6022 は別売の精密測定コードセット)、打てないなら2極法かクランプ式
  3. 測りたい抵抗値の範囲を見る。上限は 4102A 1200Ω、4105DL・6022・4300 2000Ω、4200 1500Ω(600Ω以上は確度保証外)
  4. OKランプが点かない場合は、コードの装着・補助接地棒の水分・コードの断線を先に確かめる
  5. 雨や水のかかる場所で使うかを見る。IP67 は 4105DL、IP54 は 4102A・6022
  6. 絶縁抵抗も測るなら、複合測定器の KEW 6022 も候補にする
  7. 使う前に、取扱説明書で補助接地棒の打ち方と測定の手順を読む
