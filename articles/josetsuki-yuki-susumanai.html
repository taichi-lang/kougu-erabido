雪を押しても途中で進まなくなる。雪を遠くへ飛ばしたいのに飛ばせない。充電式が思ったより早く止まる。機種が合っているかどうかは、「積雪の深さ」「雪を寄せるのか飛ばすのか」「雪の置き場までの距離」「続けて動かしたい時間と気温」の4つを確かめ、仕様表の除雪高さ・除雪機構・投雪距離・連続運転時間に当てはめて見ます。

この記事は、工進(KOSHIN)公式サイトの製品ページと、そこから開ける取扱説明書に載っている内容を、そのまま並べて整理する記事です。除雪機を雪の上で動かして比べた記事ではありません。当サイトが実機で測った記録でもありません。比較は工進1社の3機種どうしで、他社製品は入っていません。修理の手順は扱わず、扱うのは公表値と取扱説明書から言える「機種の選び直し」です。

先に結論
  • 「飛ばせない」は、ブレードタイプでは仕様どおりです。SR-350 と ESR-600 は雪を押して寄せる機構で、仕様表の投雪距離・除雪量の欄は「-」です。投雪距離(最大15m)の値があるのは、オーガ・ブロワの KSB-1170 だけです
  • 除雪高さは 250mm と 54cm で、倍以上違います。ブレードタイプ2機種は除雪高さ 250mm(取扱説明書では「最大除雪高さ」)、KSB-1170 は 54cm
  • 深い雪・固まった雪は、3機種とも取扱説明書が「雪幅を狭くする」「数回に分ける」やり方を書いています。一度に押し切る・かき込む前提の機械ではありません
  • 充電式の SR-350 は、連続運転時間 約60分が「気温が0℃のとき」の値です。備考に、気温が低くなるほど作業可能時間が短くなるとあります
  • KSB-1170 で雪が飛ばなくなったときの原因は、取扱説明書に3つ載っています。シャーボルトの折れ、異物の詰まり、雪の詰まりです

「進まない・飛ばせない・止まる」を分ける

最初に分けるのは、「機構が違う」のか「寸法を超えている」のか「動力がもたない」のかです。理由は、見る欄が違うからです。機構は除雪機構と投雪距離、寸法は除雪幅と除雪高さ、動力は連続運転時間と使用環境温度です。

KSB-1170 の取扱説明書には、混じった石や氷は雪より遠くへ飛ぶため、投雪場所には余裕をみる、という注意があります。飛ばす先に人・車・窓が無いことの確認が、機種を選ぶ前の条件になります。

積雪が除雪高さを超えているなら、一度では押せない・かき込めない寸法です。3機種の除雪幅と除雪高さを並べます。単位は公式の表記のままです(ブレードタイプは mm、KSB-1170 は cm)。

出典は工進公式の製品ページの仕様表です(2026-11-16 確認)。

  • ブレードタイプ2機種は、除雪幅・除雪高さ・ブレード高さが同じ値です。動力(充電式かエンジン式か)を替えても、一度に押せる寸法は変わりません
  • SR-350 と ESR-600 の取扱説明書は、この 250mm を「最大除雪高さ」と書いています。250mm ちょうどの雪を押し続けられるという意味かどうかは、公式表記を確認できていないため記載しません

深い雪のときのやり方は、取扱説明書に次のように書かれています。

  • SR-350・ESR-600 — 深い雪や固まった雪の場合は、サイドプレートを使って雪を切り込み、ブレードにかかる雪幅を狭くして除雪する
  • SR-350 — 深い雪の場合は、ブレードの高さを調整して、数回に分けて除雪する(ハンドルを押し下げるとブレードが上がる)
  • KSB-1170 — 積雪量が多いときは、除雪する雪がオーガハウジングの半分の高さになるように調節しながら除雪する。深い雪や重い雪でエンジンの回転数が落ちるときは変速レバーを「低速」にし、それでも落ちるならオーガハウジングにかかる雪幅を狭くする

つまり、3機種とも「深い雪は幅か高さを減らして、回数を増やす」のが公式の使い方です。毎回のように積雪が 250mm を超える場所でブレードタイプを使うと、仕様の上限の近くで回数を重ねる作業になります。積雪の深さは年と場所で変わるので、その場所でふだん一晩に積もる深さを測って見積の依頼に書くのが確実です。

雪が溜まって進まない: 握り続けないのが公式の注意

ブレードの前に雪が溜まって進まなくなるのは、取扱説明書が想定している状態です。SR-350 と ESR-600 の取扱説明書には、同じ内容の注意があります。

  • クローラーが空転するくらいの雪がブレードに溜まって前に進まなくなった状態で、走行レバーを握り続けない(故障の原因になる)
  • この場合、前後進を繰り返して、雪の量を調整する
  • クローラーの下の地面が凍結していてスリップする場合は、ハンドルを押し下げるとクローラーに荷重がかかり、駆動力を上げることができる

SR-350 には、これに加えて電気側の保護があります。取扱説明書の Q&A によると、過負荷がかかると自動的に主電源スイッチが「切」になる保護機能が付いており、原因の例として「雪が多すぎる」が挙がっています。入れ直してもすぐ「切」になる場合は内部の温度が上がりすぎているので、温度が下がるまで待つ、とあります。また「除雪する雪の量が多いと、スピードがゆっくりになることがあります」とも書かれています。製品ページの特徴欄にも「ブレードに除雪機が止まるくらい雪が溜まったまま除雪機を動かそうとしても急発進せず安心。」とあります。

KSB-1170 の取扱説明書にも、除雪部や投雪口に雪が詰まって本機が進まないときは走行レバーを握り続けない、という注意があります。前後進を繰り返して雪の量を調整するか、エンジンキーを抜いて完全に停止させてから詰まった雪を取り除く、という手順です。

どのくらいの雪の量で進まなくなるかの数値は、公式表記を確認できていないため記載しません。エンジン式でも、負荷が機種の能力を超えると仕事が進まなくなる点は共通です。エンジン機の不調を公表値から切り分ける例は、エンジン高圧洗浄機の圧力が上がらないにもあります。

飛ばなくなった: KSB-1170 の取扱説明書にある3つの原因

オーガ・ブロワの機種で「前は飛んでいたのに飛ばなくなった」なら、機種の選び直しより先に点検の話です。KSB-1170 の取扱説明書の「故障かな?と思ったら(故障と処置)」には、症状「雪が飛ばなくなった」に対して次の3つが載っています。

考えられる原因(取扱説明書)処置(取扱説明書)
オーガやブロワのシャーボルトが折れているシャーボルトの交換
オーガやブロワに異物が詰まっているエンジンを停止し、異物を除去する
オーガハウジングや投雪口に雪が詰まっているエンジンを停止し、雪かき棒で雪詰まりを取り除く

出典は工進 KSB-1170 取扱説明書(24-07 074098901、2026-11-16 に製品ページから開いて確認)です。

  • シャーボルトは、わざと折れる部品です。取扱説明書に「オーガ・ブロワのシャーボルト(3か所)は、石のかみ込みなど過度な負荷がかかった際、折れるしくみ」とあります
  • 付属品にシャーボルト(M6×20)6個とナイロンナット(M6)が入っています。製品ページのオプションパーツには、ブロワオーガシャーボルト PA-516 があります。交換用は購入店に注文する、と取扱説明書にあります
  • 雪や異物を取り除くときは、エンジンを停止してエンジンキーを抜き、付属の雪かき棒を使う、と書かれています

交換の手順そのものは、この記事では書きません。取扱説明書の該当ページに従ってください。ブレードタイプの SR-350・ESR-600 には、オーガもシャーボルトもありません。壊れる場所が少ない代わりに、雪は飛びません。回る部分に物が絡んで止まる、という点は草刈機に草が絡まる原因と似た種類の話です。

充電式がすぐ止まる: 約60分は「気温が0℃のとき」

SR-350 が思ったより早く止まるなら、連続運転時間の条件と、充電した場所の温度を見ます。同じ寸法のブレードタイプでも、動力で時間の書き方が違います。

SR-350 の備考には、時間が短くなる条件が3つ書かれています。

  • 気温が低いほど短くなる。※3 に、バッテリーの特性として、取扱温度範囲であっても気温が低くなるほど作業可能時間が短くなる、とあります
  • 0℃以下で充電すると短くなる。同じ※3 に、0℃以下での充電では満充電であっても作業可能時間が短くなるので、できるだけ温かい場所で充電する、とあります。特徴欄には「バッテリーを取り外して室内で充電できます。」とあります
  • 充電時間は長期保管後に長くなることがある。※1 に、約12時間は室温が25±5℃のときの値で、特に長期保管後は長くなることがある、とあります

気温が何℃のとき何分になるかの値は、公式表記を確認できていないため記載しません。取扱説明書の Q&A には、気温が低いと走行レバーを握ったときにバッテリー残量表示が3灯から1灯に急に減ることがあり、バッテリーの性質で異常ではない、という説明もあります。20Ah と 480Wh が並んで書かれている理由(容量とエネルギー量の違い)は電動工具のバッテリーは何Ahを買うべきかに、冬に充電式の時間が公表値どおり出ない別の例は電熱ベストが暖かくない原因にまとめています。

充電器にも条件があります。仕様表の「充電器_定格電圧」は AC 100V で、※2 に昇圧器などのトランス類を使用したり、直流電源やエンジン発電機では使用しない(発熱・火災のおそれがある)とあります。充電できる場所は、家庭用のコンセントが取れる所に限られます。トランスの容量の見方はトランスで工具が動かない、発電機の出力の見方は発電機で電動工具が動かない原因で扱っていますが、SR-350 の充電器は、容量が足りていてもこれらにつながない、というのが公式の注記です。

1回の除雪が60分を超える広さなら、仕様表から読める候補はエンジン式です。ただし、ESR-600 の「約3時間」は欄の名前が「燃料消費目安(赤レベル)」、KSB-1170 の「約3時間」は「連続運転時間(実作業時)」で、欄の名前も条件の書き方も違います。同じ条件で測った値として並べることはできません。

重さと速度: 置き場と通路で決まる

大きい機種へ選び直すと、動かす・しまう側の条件が変わります。

  • 製品寸法と重量 — SR-350 は 1,280×630×910mm・54kg、ESR-600 は 1,280×630×950mm・57.3kg、KSB-1170 は 1470×742×1076mm・145.6kg
  • 前進速度 — SR-350 は 2.0km/h(ギア 前1段)、ESR-600 は 約1.6〜2.7km/h(スロットルレバーで低速〜中速〜高速)、KSB-1170 は 0-3.0km/h(油圧式無段変速 HST)
  • 速度の調節 — SR-350 は取扱説明書に「本機の運転速度は一定」とあり、走行レバーの握り具合では変えられません
  • 動力が切れたとき — SR-350 と ESR-600 はシフトレバーを N(中立)にすると人力で動かせる、と取扱説明書にあります

通路や物置の入口の幅は、除雪幅ではなく製品寸法の全幅(630mm・742mm)で確かめます。登れる坂の角度、段差の高さについての値は、公式表記を確認できていないため記載しません。

店舗や事業所の駐車場で使う場合は、保証の条件も見ておきます。SR-350 と ESR-600 の取扱説明書の保証書には、家庭用以外(業務用など)に使用された場合の故障または損傷は、保証期間内でも有料修理になる、という項目があります。KSB-1170 の取扱説明書の保証規定には、この文言は見当たりませんでした。事業所で使う予定なら、見積のときに用途を伝えて、保証の扱いを販売店に確かめてください。

型番が決まっていなくても、この記事の下の見積依頼から、除雪する場所の広さ(駐車台数や通路の長さ)、ふだんの積雪の深さ、雪の置き場(機械の前に寄せられるか、離れた所へ飛ばす必要があるか)、1回に続けて動かしたい時間、保管場所の入口の幅を書いて送れば、見積を取れます。家庭用か事業所で使うかと、カバー・予備のバッテリーやシャーボルトをあわせて手配するかも書いてもらえると、見積が1回で済みます。

選び直す前の確認手順

上から順に
  1. 雪の置き場を決める。機械の前に寄せて置けるならブレードタイプ、離れた所へ飛ばす必要があるならオーガ・ブロワ
  2. ふだんの積雪の深さを測る。ブレードタイプ2機種の除雪高さは 250mm、KSB-1170 は 54cm
  3. 除雪する広さと、1回に続けて動かしたい時間を出す。SR-350 は約60分(気温が0℃のとき)
  4. 充電式なら、充電する場所を決める。0℃以下での充電は作業可能時間が短くなる。充電器は昇圧器・エンジン発電機につながない
  5. 飛ばす機種なら、飛ばす先を確かめる。石や氷は雪より遠くへ飛ぶ、と取扱説明書にある
  6. 保管場所と通路の幅を、製品寸法の全幅と重量で確かめる
  7. 家庭用か事業所用かを販売店に伝え、保証の扱いを確かめる

除雪機は、回る部分と走る部分のある機械です。この記事は取扱説明書の一部(除雪のしかた・故障と処置・仕様・保証書)を要点で引いただけで、始動の手順や安全上の注意の全体は書いていません。使う前に、各機種の取扱説明書を確認してください。

まとめ

  • 「飛ばせない」は、ブレードタイプでは仕様どおり。SR-350・ESR-600 は投雪距離の欄が「-」。飛ばすなら 2ステージ オーガ・ブロワの KSB-1170(投雪距離 最大15m)
  • 除雪高さは 250mm(SR-350・ESR-600)と 54cm(KSB-1170)。深い雪は、3機種とも幅か高さを減らして回数を増やすのが取扱説明書の使い方
  • 雪が溜まって進まないときは、走行レバーを握り続けない。前後進で雪の量を調整する
  • KSB-1170 で雪が飛ばなくなったら、シャーボルトの折れ・異物の詰まり・雪の詰まりの3つが取扱説明書の原因
  • SR-350 の約60分は気温が0℃のとき。気温が低いほど、また0℃以下で充電すると短くなる
  • 「最大」「約」の値は条件が機種で違う。同じ条件の値として比べない
