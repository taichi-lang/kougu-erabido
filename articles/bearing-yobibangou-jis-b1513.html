「ベアリング 型番 見方」で調べると、検索の補完は「ntn ベアリング 型番 見方」「nsk ベアリング 型番 見方」とメーカー名付きになります。「軸受 呼び番号」まで入れると「覚え方」「読み方」「jis 軸受 呼び番号」が並びます。

補完がメーカー名で割れている、という事実そのものが手がかりです。共通の読み方が1つあるなら、メーカー名を足す必要はないからです。

規格は実在します。JIS B 1513:1995「転がり軸受の呼び番号」です。そしてこの規格を読むと、メーカー名で割れる理由が規格の側に書かれていることが分かります。

この記事は、JIS B 1513:1995 の原文を読み、呼び番号のどこまでを規格が決めていて、どこから先が決めていないのかを整理する記事です。当サイトが軸受を分解したり測ったりした記録ではありません。

先に結論
  • 呼び番号は「基本番号＋補助記号」の2つに分かれます。そして補助記号は基本番号の前にも後ろにも付けられます
  • 基本番号は3つの部品でできています。軸受系列記号・内径番号・接触角記号
  • 軸受系列記号はさらに2つに分かれます。形式記号と、2桁の寸法系列記号
  • 寸法系列記号も2つに分かれます。幅系列記号と直径系列記号で、それぞれ1桁
  • 規格が「慣習的に省略されている」と書いている箇所が3つあります。形式記号・幅系列記号・接触角記号
  • 規格が「慣習的にこうなっている」と例外を認めている箇所もあります。「寸法系列からは203となるが、慣習的に213となっている」という注が実際にあります
  • 円すいころ軸受のC・Dは、寸法系列の一部に見えて接触角記号として扱われます
  • 保持器・封入グリース・材料・熱処理を表す補助記号は、規格に一覧がありません。受渡当事者間の協定によるとされています
  • 「記号が付かない」ことが区分になっている欄が2つあります。ラジアル内部すきまのCNすきまと、精度等級の0級です
  • この規格が扱うのは「一般に用いられる軸受」だけです。適用範囲にそう書かれています

呼び番号は2つに分かれ、補助記号は前にも後ろにも付く

箇条3「呼び番号の構成」が、この規格の骨格です。

「呼び番号は，基本番号及び補助記号からなり，基本番号の構成は，次による。補助記号は，受渡当事者間の協定によって，基本番号の前後に付けることができる。」

2つのことが書かれています。

1つめ。呼び番号の全部が規格の表で決まっているわけではありません。補助記号が付くかどうかは「受渡当事者間の協定によって」です。

2つめ。補助記号は前にも後ろにも付きます。「基本番号の前後に付けることができる」と書かれています。型番の先頭にある文字が、形式を表す記号なのか補助記号なのかは、この一文だけからは決まりません。

基本番号の中身 — 入れ子になった4段構造

基本番号の側は、箇条4で分解されています。整理すると、次の入れ子になります。

段構成要素規格が書いている中身
1段目軸受系列記号形式記号 ＋ 寸法系列記号(付表1に一覧)
2段目├ 形式記号軸受の形式を示す記号で、1字のアラビア数字又は1字以上のラテン文字からなる
2段目└ 寸法系列記号幅系列記号及び直径系列記号の2字のアラビア数字からなる
1段目内径番号付表2による
1段目接触角記号表1による

JIS B 1513:1995 箇条4.1〜4.5 の記載を、当サイトが構成だけ取り出して並べたものです。付表1(軸受系列記号)・付表2(内径番号)・表1(接触角記号)の記号そのものは掲載していません。当サイトが読んだ本文ページでは、これらの表の記号欄と数値欄が画像として置かれており、1つずつ確定できませんでした。

ここで押さえておく価値があるのは、形式記号は数字1字のこともあれば、ラテン文字が複数字のこともあるという点です。規格の原文がそう書いています。

「形式記号 軸受の形式を示す記号で，1字のアラビア数字又は1字以上のラテン文字からなる。」

桁数が固定されていません。だから「先頭から何文字目が何を表す」という数え方が、どの軸受にも通じるわけではありません。

そして寸法系列記号のほうは2字固定で、前の1字が幅系列、後ろの1字が直径系列です。幅と直径という別々の系列が、2桁の数字として並んでいるだけ、ということになります。

規格自身が「慣習的に省略されている」と書いている3か所

ここがこの規格でいちばん実用に効く所です。規格は、記号が抜けることを前もって認めています。しかも3か所あります。

省略される記号どの軸受で規格の書き方
形式記号寸法系列が22及び23の自動調心玉軸受形式記号が、慣習的に省略されている
幅系列記号幅系列0又は1の深溝玉軸受、アンギュラ玉軸受及び円筒ころ軸受幅系列記号が慣習的に省略されることがある
接触角記号表1の該当区分(注(1)の付いた区分)省略することができる

JIS B 1513:1995 箇条4.2 の「なお」書き、箇条4.3 の「なお」書き、および表1(接触角記号)の注(1) の記載です。

3つの書き方が微妙に違うことに注意してください。

  • 形式記号は「省略されている」 — 既にそうなっている、という書き方です
  • 幅系列記号は「省略されることがある」 — 省略される場合とされない場合の両方がある、という書き方です
  • 接触角記号は「省略することができる」 — 選べる、という書き方です

つまり「幅系列記号が無い型番」と「幅系列記号が0の型番」が、同じ軸受を指していることがあり得ます。買う前に効くのはここです。手元の型番と、探している型番の桁数が違っていても、別物とは限りません。

規格が慣習を追認している注が、実際に付いている

さらに踏み込んだ記述が、付表1の注にあります。

「(3) 寸法系列からは，203となるが，慣習的に213となっている。」

規格の表の作り方に従えば203になるはずの系列が、実際には213と呼ばれている、ということを規格自身が注記しています。そしてどちらかに直すのではなく、慣習のほうを表に載せています。

これは、規格を読むときに知っておく価値のある事実です。「規格どおりに組み立てれば型番が出てくる」わけではありません。規格の側が、実際に流通している呼び方を追認している箇所があります。

同じ型の話は同じM12の六角ナットで、厚さが3通りある(JIS B 1181)やソケットの対辺サイズでも扱いました。規格の中に旧来の系列と新しい系列が同居している、という形です。

C・Dは寸法系列の一部に見えて、接触角記号として扱われる

箇条4.3の備考に、読み違えやすい規定があります。

「円すいころ軸受の寸法系列22C, 23C又は03Dのラテン文字C又はDは，呼び番号の構成上，接触角記号として取り扱う。」

「22C」という表記の中のCは、寸法系列の名前の一部として書かれているのに、呼び番号を組み立てるときは接触角記号の位置に入ります。

つまり寸法系列の呼び名と、呼び番号の中での役割が一致していないということです。規格が「呼び番号の構成上」とわざわざ断っているのは、このためだと読めます。

接触角記号そのものは表1で規定されています。区分の切り方だけがテキストで取れました。

軸受の形式呼び接触角の区分
単列アンギュラ玉軸受10°を超え22°以下
22°を超え32°以下
32°を超え45°以下
円すいころ軸受17°を超え24°以下
24°を超え32°以下

JIS B 1513:1995 表1(接触角記号)の「軸受の形式」欄と「呼び接触角」欄の記載です。「接触角記号」欄そのものは掲載していません。当サイトが読んだ本文ページでは、この欄が画像として置かれていました。同表の注(1)に「省略することができる。」とあります。

この表から読み取れることが2つあります。

1つめ。区分の境目が形式によって違います。単列アンギュラ玉軸受は22°と32°で切れ、円すいころ軸受は24°と32°で切れます。同じ「22°」でも、アンギュラ玉軸受では下の区分の上限、円すいころ軸受では区分の途中です。

2つめ。すべて「〇°を超え〇°以下」です。境目の値がどちら側に入るかが、規格の書き方で決まっています。

補助記号 — 一覧のある部分と、無い部分

箇条5「補助記号」は、たった2文です。そしてその2文目が重要です。

「補助記号は，付表3による。
なお，保持器，封入グリース，材料，熱処理などの仕様を示す補助記号は，受渡当事者間の協定による。」

付表3に一覧があるのは前半だけで、保持器・グリース・材料・熱処理は一覧の外です。規格に記号表がありません。

ここが、冒頭の「ベアリング 型番 見方」の補完がメーカー名で割れていた理由に当たります。グリースや保持器を表す記号は、規格が定めていないので、メーカーごとの取り決めになります。当サイトはメーカーの記号表を確認していないので、その中身については何も書きません。書けるのは「JISには無い」というところまでです。

付表3の側に何が載っているかは、仕様の区分名がテキストで取れました。

仕様付表3に挙がっている内容・区分
内部寸法主要寸法及びサブユニットの寸法が ISO 355 に一致するもの
シール・シールド両シール付き / 片シール付き / 両シールド付き / 片シールド付き
軌道輪形状内輪円筒穴 / フランジ付き / 内輪テーパ穴(基準テーパ比 1/12) / 内輪テーパ穴(別の基準テーパ比) / 輪溝付き / 止め輪付き
軸受の組合せ背面組合せ / 正面組合せ / 並列組合せ
ラジアル内部すきまC2すきま / CNすきま / C3すきま / C4すきま / C5すきま(JIS B 1520 参照)
精度等級0級 / 6X級 / 6級 / 5級 / 4級 / 2級(JIS B 1514 参照)

JIS B 1513:1995 付表3(補助記号)の「仕様」欄と「内容又は区分」欄の記載です。「補助記号」欄そのものは掲載していません。当サイトが読んだ本文ページでは、この欄が画像として置かれていました。注(5)に「JIS B 1520参照」、注(6)に「JIS B 1514参照」とあります。内輪テーパ穴の基準テーパ比は本文に2行あり、当サイトが確定できたのは 1/12 の側だけです。

この表で、買う前に効くところが2つあります。

1つめ。「記号が付かない」ことが1つの区分になっている欄が2つあります。ラジアル内部すきまのCNすきまと、精度等級の0級です。付表3の補助記号欄では、この2つの行だけ「なし」と書かれています。型番の末尾に何も付いていないことが、標準のすきま・標準の精度等級を意味するということになります。

2つめ。すきまと精度等級は、それぞれ別の規格が中身を持っています。すきまは JIS B 1520、精度等級は JIS B 1514。「C3」がどれだけのすきまなのかは、この規格には書かれていません。

止め輪付きが補助記号の1つとして挙がっているのも、覚えておく価値があります。止め輪そのものの規格は別で、止め輪(スナップリング)の「呼び」は、C形とE形で指している場所が違うで扱っています。

この規格が扱っているのは「一般に用いられる軸受」だけ

適用範囲を最後に確認します。

「この規格は，JIS B 1512に規定する主要寸法をもつ転がり軸受（以下，軸受という。）のうち，一般に用いられる軸受の呼び番号について規定する。」

条件が2つ重なっています。

  • JIS B 1512(転がり軸受の主要寸法)に規定する主要寸法をもつものであること
  • そのうち一般に用いられる軸受であること

この規格は、すべての軸受の呼び番号を規定しているわけではありません。2段の絞り込みが適用範囲の1文の中に入っています。

付表1の注(2)にも、範囲の話が出てきます。「軸受系列NA48, NA49, NA59及びNA69の軸受から内輪を除いたサブユニットの系列記号である」という注で、内輪の無い状態にも系列記号が振られていることが分かります。

また、内径番号については箇条4.4に例外規定があります。「ただし，複式平面座形スラスト玉軸受の内径番号は，同じ直径系列で同じ呼び外径をもつ単式平面座形スラスト玉軸受の内径番号と同一とする。」複式のほうが単式に合わせる、という向きが決められています。

型番を照合するときに効く順番
  • ① 桁数の違いは別物の証拠になりません。形式記号と幅系列記号は、規格が「慣習的に省略される」と明記しています
  • ② 末尾に何も付いていない＝標準です。CNすきま・0級は補助記号が「なし」の区分です
  • ③ 末尾の記号がJISの表に無いなら、それはメーカー側の記号です。保持器・グリース・材料・熱処理は受渡当事者間の協定によります
  • ④ 先頭の文字も補助記号でありうることに注意します。補助記号は「基本番号の前後」に付けられます
  • ⑤ C・Dは接触角記号として扱われます(円すいころ軸受の22C・23C・03D)
  • ⑥ すきまと精度等級の中身は別の規格(JIS B 1520 と JIS B 1514)にあります

同じ「番号や記号で買う部品」として、当サイトではOリングのPとGは「太さの系列」ではなく用途の区分、キー溝の「JIS B 1301:2009」は追補で、寸法は1996年のまま、平行ピン(ノックピン)の公差は「h7」ではないを扱っています。

「メーカー指定でしか買えない部品」という切り口では、電動工具のカーボンブラシは「当社指定」で買う部品が同じ形です。規格の外にある部分は、メーカーの側にしか答えがありません。

グリースの話はハンマードリルの「グリスアップ」は2つの別物で扱っています。密封されている側には触らないという切り分けは、封入グリースの記号が規格の外にあることとも通じます。

呼び方の中に国際規格の番号が直接入る例はいもねじは「本体に何も表示しない」と規格が決めている(JIS B 1177)にあります。ISO 4026〜4029 の4つが、先端形状そのものを指しています。

呼びの記号がどの規格に属するかで意味が変わる例として管用ねじの R・Rc・Rp・G は「テーパか平行か」だけでは決まらない(JIS B 0203 / B 0202)があります。平行めねじの Rp と G は、属する規格が違います。

軸まわりの位置決めに使うピンの側はテーパピンの「A種・B種」は精度の等級ではない(JIS B 1352 / JIS B 1358)にまとめました。こちらも「呼び方のどこまでを規格が決めているか」が論点です。
