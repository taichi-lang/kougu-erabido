「ノックピン 公差」の検索補完は「h7」「m6」「p6」「使い分け」「圧入」で10本埋まり、「平行ピン 公差」も「m6」「h7」「圧入」「b種」「a種」「下穴」で埋まります。m6 と h7 のどちらが正しいのかで止まっている状態です。

規格は実在します。JIS B 1354:2012「平行ピン」です。そしてこの規格がピン側に定めている公差域クラスは、m6 と h8 の2つです。h7 は出てきません。表1の注aの原文は次のとおりです。

「dの公差域クラスm6及びh8は、JIS B 0401-2による。なお、受渡当事者間の協定によって、他の公差域クラスを用いることができる。」

この記事は、JIS B 1354:2012 の原文を読み、平行ピンの公差・材料・表面性状・呼び方が規格上どう決められているかを整理する記事です。当サイトがピンを測った記録ではありません。

先に結論
  • 規格が示している公差域クラスは m6 と h8 の2つです。h7 はこの規格の本文に出てきません
  • それ以外も使えます。ただし「受渡当事者間の協定によって」という条件付きです
  • 公差域クラスを選ぶと、要求される表面粗さまで変わります。m6 は Ra≦0.8µm、h8 は Ra≦1.6µm
  • 公差域クラスは呼び方の中に入ります。「6 m6×30」のように、呼び径と呼び長さの間に入ります
  • 包装の外面への表示項目にも入っています。c)「dの公差域クラス」が必須項目です
  • 適用範囲は呼び径 0.6mm〜50mm です。鋼製とオーステナイト系ステンレス鋼製
  • 硬さは3系統に分かれています。125〜245HV30 / 255〜327HV30 / 210〜280HV30
  • 端面の形状は規格が決めていません。「受渡当事者間の協定による」と表1に書かれています

h7 はどこから来るのか — 規格が持っているのはピン側だけ

この規格の適用範囲(箇条1)の原文です。

「この規格は、呼び径dが0.6 mmから50 mmまでの鋼製及びオーステナイト系ステンレス鋼製の平行ピンの特性について規定する。」

規定しているのは「平行ピンの特性」です。ピンを差す穴の側については、この規格は何も規定していません。したがってh7 という記号がこの規格の本文に出てこないこと自体は、h7 が誤りだという意味にはなりません。h7 は穴の公差域クラスとして使われうる記号であり、ピン側の規格の外にあるということになります。

⚠ 当サイトは「ピン穴を h7 にする」と書いている一次情報を確認していません。そのため穴側をどう取るべきかについては、この記事では何も書きません。ここで確定できるのは、JIS B 1354 がピンに与えている公差域クラスは m6 と h8 であるという1点です。

JIS B 1354:2012「平行ピン」の箇条1、表1(平行ピンの形状・寸法)およびその注a・注bの記載を整理したものです。

公差域クラスを選ぶと、表面粗さの要求まで変わる

表2(製品仕様)の「表面粗さ」の欄の原文です。

「公差域クラスm6のピン：Ra≦0.8 μm／公差域クラスh8のピン：Ra≦1.6 μm」

公差域クラスは径の許容差だけの話ではありません。m6 を指定すると、表面粗さの上限も同時に半分になります。逆に h8 を選べば、径の許容差だけでなく表面の要求も緩い側になります。

買う前に効くのはここです。「m6 と h8 のどちらでもよい」という判断をする場合、比べているのは径の公差だけではありません。2つの項目が同時に切り替わります。

1つの選択が複数の要求を同時に動かす形は、防じんマスクの「DS2」は3つの別のことを同時に言っている、安全靴の「S種」にもあります。

材料と硬さ — 3系統に分かれている

表2(製品仕様)の材料欄には、3つの系統が並びます。

系統材料硬さ
鋼(St)・硬化処理を施さないピン—125HV30〜245HV30
鋼(St)・焼入焼戻しを施すピンJIS G 4051 の S43C〜S50C255HV30〜327HV30
オーステナイト系ステンレス鋼(A1)JIS B 1054-1 の A1210HV30〜280HV30

JIS B 1354:2012 表2(平行ピンの製品仕様)の記載です。注aに「受渡当事者間の協定によって、他の材料を使用することができる。」とあります。

硬化処理を施さない鋼(125〜245HV30)と、ステンレス(210〜280HV30)は範囲が重なります。硬さだけを見て材質を推定することはできない、ということになります。3つの範囲を1本の順序に並べることも、この規格の中ではできません。

なお「焼入焼戻しを施すピン」は、対応国際規格 ISO 2338 には無いものです。附属書JAの対比表に「JISでは、ISO規格にない“焼入焼戻しを施すピン”を追加」と書かれています。逆にJIS側では、ISO の適用範囲にある「硬化処理をしないピン」という限定を削除しています。

表面仕上げについても規定があります。鋼の側は「生地の状態：受渡当事者間の協定がない場合は、保護潤滑皮膜付きの自然な仕上げ状態でピンを供給する。」、ステンレスの側は「生地の状態：自然な仕上げ状態でピンを供給する。」です。鋼のほうにだけ、協定が無いときの既定として保護潤滑皮膜が置かれています。

表面状態の要求は1文です。「ピンは、凹凸又は有害な欠陥があってはならない。ばりは、ピンのどの部分にもあってはならない。」ばりについては「どの部分にも」と場所を限定していません。

呼び方 — 公差域クラスが名前の一部になっている

箇条6の呼び方の例を、原文のまま引きます。

  • 「平行ピンJIS B 1354−ISO 2338−6 m6×30−St」(呼び径 d＝6mm、公差域クラス m6、呼び長さ l＝30mm、硬化処理を施さない鋼製)
  • 「平行ピンJIS B 1354−6 m6×30−St−S45C−Q」(同じ寸法で、焼入焼戻しを施した S45C 鋼製)
  • 「平行ピンJIS B 1354−ISO 2338−6 m6×30−A1」(同じ寸法で、鋼種区分 A1 のオーステナイト系ステンレス鋼製)

3つを見比べると構造が分かります。公差域クラスは呼び径のすぐ後ろに入り、「6 m6×30」で1つのまとまりになります。そして焼入焼戻し品(例2)にだけ ISO 2338 が入りません。ISO に無い追加項目だからです。末尾の「Q」が焼入焼戻しを表しています。

包装の表示(箇条7.2)にも公差域クラスが入ります。必須項目はa) 規格番号又は規格名称 b) 呼び径d×呼び長さl c) dの公差域クラス d) 材料 e) 数量 f) 指定事項 g) 製造業者名又はその略号の7つです。

一方、箇条7.1は「製品の表示については、特に規定しない。」としています。ピン単体を見ても m6 か h8 かは分かりません。包装から離した時点で、その情報は失われることになります。

同じ「表示は包装にあり、部品単体には無い」形は、割りピン、すりわり付き小ねじにもあります。

受入検査は別の規格へ送られている

表2の受入検査の欄は1行です。「受入検査手順は、JIS B 1091による。」この規格の中には検査手順が書かれていません。

引用規格として挙げられているのはJIS B 0101(ねじ用語)、JIS B 0401-2、JIS B 1010(締結用部品の呼び方)、JIS B 1044(電気めっき)、JIS B 1054-1、JIS B 1091(受入検査)、JIS G 4051です。公差の数値・呼び方・受入検査・材料の4つが、それぞれ別の規格に置かれているという構造になります。

規格が本体で数値を持たず、別規格へ送る形はボルト穴径及びざぐり径、皿ねじの頭部形状にもあります。

買う前に確認できること

確認の順序
  • ① ピン側の公差域クラスは m6 か h8 のどちらか。規格が並べているのはこの2つです
  • ② それ以外を使うなら「協定」が要る。規格の側がそう書いています
  • ③ m6 を選ぶと表面粗さの要求も上がる。Ra≦0.8µm と Ra≦1.6µm の差です
  • ④ 買うときは呼び方の「6 m6×30」の部分を見る。公差域クラスが名前に入っています
  • ⑤ 包装から出したら判別できない。製品の表示は「特に規定しない」です
  • ⑥ 硬さで材質は推定できない。鋼(未硬化)とステンレスの範囲は重なります
  • ⑦ 焼入焼戻し品は JIS 独自の追加。呼び方に ISO 2338 が入らず、末尾に Q が付きます
  • ⑧ 端面の形状は規格で決まらない。「受渡当事者間の協定による」です

同じ「ピン」でも割りピンは全く別の規格で、呼びの意味も違います。割りピンの「呼び径」は穴の径であってピンの太さではないを参照してください。呼びの数字が部品そのものを指していない形は止め輪の呼びはC形とE形で指す場所が違う、圧着端子の「1.25」にあります。

穴の側の規格は「ざぐりの深さ」にJISの数値は無い、タップの下穴径にあります。許容差そのものの読み方はスパナのガタつきは不良ではない、ノギスの「精度」は1つの数字ではない、コンベックスの「JIS1級」にあります。

公差域クラスの記号が製品の性格を決める形は、ちょうボルト(8g)・ちょうナット(7H)や六角袋ナット(6H)にもあります。引いている規格の「部」まで違うので、記号だけでは体系が決まりません。

公差域クラスで相手との関係が決まる部品としては、キー溝の「JIS B 1301:2009」は追補で、寸法は1996年のままも同じ形です。キー溝の許容差は軸径ではなく、滑動形・普通形・締込み形という結合の種類で選びます。軸まわりではベアリングの型番は、途中までしかJISが決めていない(JIS B 1513)、OリングのPとGは「太さの系列」ではなく用途の区分(JIS B 2401-1)も参照してください。

軸や部品を押さえて止めるもう一方の手段である止めねじは、いもねじは「本体に何も表示しない」と規格が決めている(JIS B 1177)にまとめました。

同じ「ピン」でもテーパ側は別番号の規格です。テーパピンの「A種・B種」は精度の等級ではない(JIS B 1352 / JIS B 1358)では、区分の軸が公差域クラスではなくテーパ部の表面粗さであること、1級・2級は本体ではなく附属書の区分であることを整理しています。この記事の m6・h8 と、あちらの A種・B種は、まったく別の物差しです。
