「丸ノコ 集じん」で調べると、検索の補完には「集塵機」「集塵カバー」「集塵袋」と並んで、「自作」「ペットボトル」という語が出てきます。上位に並ぶ記事も、自作の作例や、径をどう合わせたかという工夫の話が中心です。

それだけ、既製品の組み合わせ方が分かりにくいということでもあります。実際、マキタの取扱説明書を読むと、丸ノコに集じん機をつなぐには少なくとも3つの部品が要ると書かれていました。しかもそのうち2つは、取扱説明書に品番が載っていません。

この記事は、マキタの充電式マルノコの取扱説明書3点を確認し、集じんのために何がどこまで指定されているかを整理する記事です。社外品や自作の適合可否は判定しません。

  • ダストノズルは標準付属品ではなく、別販売品です。3機種とも「別販売品のご紹介」の欄に載っています
  • 部品番号は機種で違います。165mm の HS001G / HS002G は196995-4、85mm の HS300D / HS301D はA-51817 です
  • ノズルを買っても、まだ集じん機に届きません。取扱説明書は「ダストノズルに合うホース、ジョイントを使用して集じん機へ接続してください」と書いています
  • そのホースとジョイントの品番は、取扱説明書に載っていません。「詳細は総合カタログを参照してください」と書かれています
  • 取り付けはツマミネジです。「本製品に図のようにツマミネジで取り付けます」と書かれています

  • 安全上のご注意の側にも、逆向きの記載があります。「集じん装置が接続できるものは接続して使用してください」

この一致には意味があります。「機種が違えばアクセサリも全部違う」のであれば、番号が違うことに情報はありません。ところがここでは、アクセサリ全体は共通で、電源まわりだけが分かれています。そのうえで165mm の機種はノズルの番号が別でした。

つまり、ノズルを分けているのは「電圧」でも「発売時期」でもなく、本体の大きさ側の事情だと読めます。85mm の2機種は本体寸法(長さ300mm と 313mm)も回転数(1,400 と 1,500 min-1)も違いますが、ノズルは同じです。

これは、部品番号の一致・不一致から読み取った推測です。マキタが「ノズルは本体の大きさで分かれる」と書いているわけではありません。取扱説明書に、分類の基準を説明した文は見当たりませんでした。

「載っているものが一致する」ことを先に示してから差を語る、という手順は、当サイトが高圧洗浄機の延長ホースで使った形と同じです。あちらは共通の別販売品5点が一致したうえで、延長ホースという一点だけが分かれている、という示し方でした。

ノズルを買っても、まだ集じん機に届かない

ここが、この記事でいちばん伝えたい部分です。取扱説明書の「集じん機との接続」の項目には、次の一文があります。

取扱説明書の記載(原文)
  • 本製品にダストノズルを取り付けることにより当社集じん機と接続でき、衛生的に作業をすることができます。
  • 本製品に図のようにツマミネジで取り付けます。
  • ダストノズルに合うホース、ジョイントを使用して集じん機へ接続してください。詳細は総合カタログを参照してください。

株式会社マキタ 165mm 充電式マルノコ HS001G / HS002G 取扱説明書「ダストノズルについて」「ダストノズルの取り付け方」「集じん機との接続」の記載です。引用は原文のままです。

「ダストノズルに合うホース、ジョイントを使用して」。この一文が、部品を2つ追加しています。

必要なもの取扱説明書に品番の記載取扱説明書がどこを見ろと書いているか
① ダストノズルあり(196995-4 / A-51817)別販売品のご紹介
② ホースなし総合カタログ
③ ジョイントなし総合カタログ

同取扱説明書の記載を整理した表です。「なし」は、参照した取扱説明書に品番の記載を確認できなかったという意味です。

この構造が、集じんの組み合わせが分かりにくい理由だと考えられます。本体の取扱説明書だけを最後まで読んでも、必要な3点のうち2点は品番が確定しません。「総合カタログを参照してください」というのが、取扱説明書自身の答えです。

そして「ジョイント」という語が出てくること自体が手がかりです。ホースを1本つなげば済むなら、ジョイントは要りません。メーカー自身が、径や形をつなぎ替えるための部品を前提にしているということになります。

接続や変換のための部品が別に用意されているとき、その2つは直接つながらない。これは当サイトが手がかりとして扱ってきた形で、高圧洗浄機の旧機種アクセサリ用アダプタ、レーザー墨出し器の1/4インチ雲台付き三脚、ブロワのフレキシブルホースに続く4件目の実例になります。

集じん機側のホースの径については、当サイトの集じん機のホース径(φ28・φ32・φ38)で扱いました。あちらは径そのものが選択の軸になっているという話でした。丸ノコ側は、その径に合わせるための部品が要る側にあたります。

「つながないなら外せ」とも書かれている

もう1つ、注意の欄に書かれていることがあります。

取扱説明書の記載(原文・注)
  • 集じん機を接続しない場合は、ダストノズルをはずしてください。ダストノズルを取り付けたまま使用すると、切りくずがつまる場合があります。

株式会社マキタ 165mm 充電式マルノコ HS001G / HS002G 取扱説明書「集じん機との接続」の注の記載です。85mm の HS300D / HS301D の取扱説明書にも、同じ内容の注があります。

これは、付けっぱなしを前提にしていないという意味です。ノズルは常設の部品ではなく、集じん機をつなぐときに付け、つながないときは外すという扱いで書かれています。

理由も書かれています。「切りくずがつまる場合があります」。吸わせない状態で口を狭めると、そこに切りくずがたまるという話です。取り付けがツマミネジなのは、この付け外しを工具なしでできるようにするためと読めます。

この記載は、電源方式も刃の大きさも違う機種の取扱説明書で共通していました。40Vmax の165mm 機と、10.8V の85mm 機です。1機種の特記事項ではありません。

一方で、安全上のご注意は「接続できるものは接続しろ」と書いている

取扱説明書の別の場所には、逆向きの記載があります。

取扱説明書の記載(原文)
  • 集じん装置が接続できるものは接続して使用してください。
  • 充電工具に集じん機などが接続できる場合は、これらの装置を確実に接続することで(粉じんに関する危険が低減できます)

同取扱説明書「安全上のご注意」の記載です。3機種とも同じ項目があります。

2つの記載は矛盾していません。安全上のご注意が言っているのは「つなげるならつなげ」、集じん機との接続の注が言っているのは「つながないならノズルを外せ」です。どちらも、中途半端な状態を避けろという同じ方向を向いています。

この2つを合わせて読むと、ダストノズルは「あると便利な追加品」ではなく、集じん機とセットで運用する部品として書かれていることが分かります。

刃の側は、径に「使用できる範囲」が別に書かれている

「ノコ刃寸法」は標準の刃、「使用できるノコ刃の外径」は許容範囲です。この2つが別の欄になっているのは、165mmの機械に165mmの刃しか付かないわけではないということを、メーカーが自分で書いているからです。

ただし内径は20mmのまま、範囲の記載がありません。外径には範囲があり、内径には無い。これは、当サイトのチップソーの内径と丸ノコの刃のサイズで扱った「外径より先に内径が決まっている」という構造が、仕様表の欄の作りにそのまま出ている例です。

手順
  • ① 自分の機種の取扱説明書で「別販売品のご紹介」を開き、ダストノズルの部品番号を控える。機種で違います
