「ドリルチャック JT MT 違い」で調べると、関連する検索は「ドリルチャック 規格」「ドリルソケット ドリルスリーブ 違い」「電動ドリルチャック 種類」「ドリルチャック 六角軸」で埋まります。手元のチャックと主軸が合うのかどうかを確かめたい、という向きの言葉です。

この2つの記号は、しばしば「JTは工具側の規格、MTは工作機械側の規格」というふうに、別々の出どころのものとして説明されます。しかし規格の原文を開くと、そうではありません。

ジャコブステーパもモールステーパも、JIS B 4634:1998「ドリルチャック」という1本の規格の、同じ附属書の中に、附属書表1と附属書表2として並んで置かれています。

この記事は、JIS B 4634:1998 の原文を読み、規格が何をどこまで決めているかを整理する記事です。当サイトがチャックを差し替えて確かめた記録ではありません。

先に結論
  • JT(ジャコブステーパ)と MT(モールステーパ)は、同じ JIS B 4634:1998 の同じ附属書に規定されています。附属書表1 がジャコブステーパ、附属書表2 がモールステーパです。別の規格に分かれてはいません
  • この規格は1998年に2つの規格を統合したものです。まえがきに「JIS B 4634 : 1995は改正され，この規格に置き換えられるとともに，JIS B 6001 : 1992は廃止され，この規格に統合される。」とあります。統合前は「携帯電気ドリル用チャック」と「工作機械用ドリルチャック」が別の規格でした
  • ジャコブステーパには「2ショートテーパ」という別枠があります。附属書表1 の行に、テーパ番号とは別に「2ショートテーパ」が置かれています。「JT2」という言い方だけでは、この2つを区別できません
  • 規格自身が、使わないほうがよい番号を名指ししています。附属書表1 の備考2 は「テーパ番号(4)及び(5)は，できる限り使用しないようにする。」です
  • ねじ式チャックのねじは、ミリねじではありません。附属書表5 の備考に「ユニファイ細目ねじの呼び3/8-24UNF及び1/2-20UNF」、等級は2Bと書かれています
  • 円周振れの許容値は、種類によって2水準あります。表1 に0.08以下と0.20以下の2つの値が出てきます(単位 mm)
  • 記号 E だけは、工作機械用と携帯電気ドリル用の区別がありません。表1 の注(1) に「記号Eについては，工作機械用と携帯電気ドリル用の区別はない。」とあります
  • チャックには表示が義務づけられています。呼び寸法・記号・ねじ式の場合はねじの呼び・製造業者名又はその略号の4つです
  • ⚠ この記事にテーパの寸法の数値は1つもありません。当サイトが読んだ本文ページでは、附属書表1・表2 の数値部分が画像で置かれており、1つも確定できませんでした

JT と MT は、同じ規格の中の別の表である

まず、規格の構成です。JIS B 4634:1998 には附属書が1つだけあり、その表題はまえがきに次のように書かれています。

附属書（規定）　ドリルチャックのテーパの寸法，テーパゲージの許容差及びユニファイ細目ねじ

この附属書の中身は、箇条の順に次のように並んでいます。

附属書の箇所何を規定しているか
附属書表1ジャコブステーパの寸法
附属書表2モールステーパの寸法
附属書表3ジャコブステーパゲージの許容差
附属書表4モールステーパゲージの許容差
附属書表5ユニファイ細目ねじ部の寸法

つまり JT と MT は、規格の中では対等な2つの表です。本体の 4.1 の備考1 も「ジャコブステーパ，モールステーパ及びユニファイ細目ねじは，附属書による。」と、3つを同列に並べて書いています。

チャックの取付け方が3通りある(テーパで嵌める方式が2種、ねじで留める方式が1種)ということを、規格は「附属書のどの表を見るか」という形で書き分けています。

この規格は、2つの規格を統合してできている

JT と MT が1本の規格に同居している理由は、まえがきに書かれています。

これによってJIS B 4634 : 1995は改正され，この規格に置き換えられるとともに，JIS B 6001 : 1992は廃止され，この規格に統合される。

さらに改正の目的として、「類似のJIS B 4634 : 1995（携帯電気ドリル用チャック）とJIS B 6001 : 1992（工作機械用ドリルチャック）との2規格を統合すること」と明記されています。

ここから分かることが2つあります。

  • 1998年より前は、電動ドリル用と工作機械用が別々の規格でした。古い資料が「JIS B 6001」を挙げていることがありますが、その規格は廃止されており、内容はこの規格に入っています
  • 現在は1本の規格が両方を扱っています。そのため、規格の中では「工作機械用」「携帯電気ドリル用」が種類の区分として現れます

序文には、テーパの寸法の出どころも書かれています。「1974年に第1版として発行されたISO 239, Drill chuck tapersを元に，対応する部分（テーパの寸法）については技術的内容を変更することなく，附属書として作成した」とあり、対応国際規格は ISO 239 : 1974 Drill chuck tapers です。

種類は3つの軸で分かれ、円周振れの値が違う

箇条3 は「チャックの種類及び記号は，表1による。」とだけ書いています。その表1 に現れる区分は次の3つの軸です。

  • 用途 — 工作機械用 / 携帯電気ドリル用
  • 取付け方式 — テーパ式 / ねじ式
  • 形 — 普通形 / 軽量形

そして表1 には、円周振れとして 0.08以下・0.20以下・0.20以下 の3つの値が並んでいます(単位 mm)。3列のうち1列だけが 0.08 で、残る2列が 0.20 です。

⚠ どの列がどの種類に対応するかは、当サイトでは確定していません。当サイトが読んだページでは表の罫線が失われており、見出しの並び順(工作機械用テーパ式普通形 / 携帯電気ドリル用テーパ式普通形 / 携帯電気ドリル用ねじ式軽量形)と値の並び順が一致するかどうかを確かめる手段がありませんでした。書けるのは「2水準あり、うち1つが 0.08、2つが 0.20 である」までです。

一方、注(1) は本文の文字として読めます。

記号Eについては，工作機械用と携帯電気ドリル用の区別はない。

記号は種類を表すものですが、E だけは用途の区別を持たない、と規格自身が断っています。記号を見れば用途が分かる、という読み方はここで1つ崩れます。

「JT2」だけでは足りない — 2ショートテーパという別枠がある

附属書表1(ジャコブステーパの寸法)の行には、テーパ番号の並びとは別に「2ショートテーパ」という項目が置かれています。

つまりジャコブステーパの「2」には、通常の2と、ショートテーパの2があるということです。「JT2」という表記だけでは、この2つのどちらであるかは決まりません。

さらに、同じ附属書表1 の備考2 は次のように書いています。

テーパ番号(4)及び(5)は，できる限り使用しないようにする。

規格が、自分が規定している番号のうち2つについて「できる限り使用しないように」と書いている形です。廃止したのではなく、表には残したまま、使用を控えるよう促しています。

⚠ 注(4)(5) が指しているテーパ番号そのものは、当サイトでは確定していません。注番号の (4)(5) は表中の該当セルに付されており、そのセルが画像であるためです。「JT4 と JT5 のことである」とは書きません。

なお、附属書表1 の備考1 は「d3は計算値である。」です。表に載っている寸法のうち d3 は、測って決めた値ではなく計算で出した値である、と規格自身が明示しています。同じ備考は附属書表2(モールステーパ)にも付いています。

ねじ式チャックのねじは、ミリねじではない

取付け方式が「ねじ式」のチャックについて、規格は 5.6 で「チャックのユニファイ細目ねじ部の寸法は，附属書表5による。」と定めています。

その附属書表5 の備考には、呼びが本文の文字として書かれています。

ユニファイ細目ねじの呼び3/8-24UNF及び1/2-20UNFの基準山形及び基準寸法は，JIS B 0208による。また，その許容限界寸法は，JIS B 0212に規定する等級の2Bによる。

ここから確定できることは3つです。

  • ねじ式チャックのねじは、インチ系のユニファイ細目ねじです。ミリねじではありません
  • 呼びは 3/8-24UNF と 1/2-20UNF の2つが挙げられています
  • めねじの等級は 2B です。基準山形・基準寸法は JIS B 0208、許容限界寸法は JIS B 0212 という、別の規格に投げられています

また、附属書表5 には「適用するチャックの呼び寸法」の列があり、本文の文字として「6.5及び10」「10及び13」という区分が読めます。呼び寸法によって、使われるユニファイ細目ねじの呼びが分かれているということです。

⚠ どちらの呼びが 6.5及び10 で、どちらが 10及び13 かは確定していません。対応関係は表の中で示されており、その部分が画像であるためです。

検査の側も、ミリねじ用の道具ではないことが書かれています。6.6 は「JIS B 0256に規定する2Bねじ用限界ゲージを用いて，有効径及び内径を測定する。」です。

規格が数値で決めている品質 — 硬さ・当たり・ずれ

寸法の表は画像で読めませんでしたが、品質の箇条(箇条5)には、本文の文字として数値が書かれています。ここは確定できました。

箇所規格が求めている値根拠
ドリルをくわえる部分(つめ)の硬さ53 HRC 又は 560 HV 以上5.3
カバー及びハンドルの歯部の硬さ30 HRC 以上 又は 300 HV 以上5.3

注目すべきは 5.4 と 5.5 がジャコブステーパとモールステーパの両方に、同じ文でかかっていることです。5.4 の表題は「ジャコブステーパ及びモールステーパ大径部の寸法許容差」、5.5 は「ジャコブステーパ及びモールステーパ穴部の当たり」で、±1 mm も 75 % も、JT と MT で値が分かれていません。

測り方も具体的です。6.4・6.5 は、ゲージに「一様に光明丹を塗って」穴部に差し込み、「一様に回して当たりを測定する」と書いています。当たりの良し悪しは、当てて見るものであると規格が手順まで決めている形です。

把握力については、5.7 が「表4に示すねじりモーメントを加えたとき，試験棒が滑ったり各部に異状があってはならない。」と定めています。単位は N・m です。⚠ 呼び寸法ごとの値は表4 にあり、当サイトでは確定できていません。また 6.7 の備考として「試験棒の硬さは，55 HRC以上とする。」が本文の文字で読めます。

現物に何が表示されているか

箇条9 は、チャックの本体又はカバーに「容易に消えない方法で」次の4つを表示するよう定めています。

  • a) 呼び寸法
  • b) 記号
  • c) ねじ式の場合はねじの呼び(附属書表5のユニファイ細目ねじの呼びによる)
  • d) 製造業者名又はその略号

c) が「ねじ式の場合は」と条件付きである点が、この記事の主題に効いてきます。ねじ式であればねじの呼びが本体に出ますが、テーパ式の場合に「テーパ番号を表示せよ」という項目は、箇条9 にありません。

また、製品の呼び方(箇条8)は「規格番号又は規格名称，種類，呼び寸法及び記号による。」で、備考は「種類又はその一部は省略してもよい。」です。規格自身が挙げている例は次の4つです。

例1. JIS B 4634 工作機械用テーパ式普通形 6.5 MG
例2. JIS B 4634 工作機械用（又は携帯電気ドリル用）テーパ式普通形 6.5 E
例3. JIS B 4634 携帯電気ドリル用テーパ式軽量形 6.5 EL
例4. JIS B 4634 携帯電気ドリル用ねじ式軽量形 6.5 ELB

例1 は「ドリルチャック　工作機械用テーパ式普通形 6.5 MG」「JIS B 4634 6.5 MG」という短い書き方も併記されています。種類を省略してよいので、現物や図面には「6.5 MG」のような、記号と呼び寸法だけの表記が現れうるということです。

⚠ 記号 MG・E・EL・ELB がそれぞれ何を意味するかは、表1 で定義されています。その定義のセルは当サイトが読んだページでは画像であり、当サイトは「MG は工作機械用テーパ式普通形の記号である」と断定していません。ここに挙げたのは、箇条8 の例文にその組合せで現れている、という事実だけです。

この記事が答えていないこと

最初の検索語に戻ります。「手元のチャックと主軸が合うか」という問いに、この規格だけでは答えが出ません。理由は2つあります。

  • 寸法の表が読めていません。附属書表1・表2 の数値が画像であるため、テーパ番号ごとの径や長さを1つも確定できていません
  • この規格が扱っているのはチャック側です。適用範囲は「ドリルチャック（以下，チャックという。）及びそのハンドル」であり、主軸側・アーバ側の規格は、この規格の中にありません

ただし、附属書表1・表2 のどちらにも「適用するチャックの呼び寸法」という列があることは本文から確認できます。チャックの呼び寸法とテーパ番号の対応は、規格の中に存在します。当サイトがその中身を読めていない、というだけです。

「同じ言葉が指す先が1つに決まらない」という形は、この記事だけのものではありません。同じ形の例としてテーパピンの「A種・B種」は精度の等級ではない(JIS B 1352 / JIS B 1358)があります。あちらは同じ記号が2つの規格で別の意味を持つ例、こちらは1つの表の中に「2」と「2ショート」が並んでいる例です。

規格が「使わないほうがよい」と自分で書いている例としては管用ねじの R・Rc・Rp・G は「テーパか平行か」だけでは決まらないがあります。あちらの附属書は「次回改正時に廃止年限を明らかにする。」で、この記事の「できる限り使用しないようにする。」とは強さが違います。

チャックの呼び寸法そのもの(10mm と 13mm)についてはドリルドライバーのチャック径 10mmと13mmの違いを、インチ系の寸法が混ざる話は六角レンチのサイズが合わない — 呼び径から選んでいることが原因になっている場合を参照してください。

本体に何が表示されるかという話は電動工具の「本体のみ」は何が入っていないのかといもねじは「本体に何も表示しない」と規格が決めている(JIS B 1177)にあります。この記事の「ねじ式の場合はねじの呼び」も、表示義務が条件付きである例です。

軸側が入るかどうかという同じ型の問いはホールソーは刃だけでは付かない — シャンクは「刃先径」と「工具の取付部」の2軸で決まるとトリマービットの軸径6mmと6.35mm(1/4インチ)は別物にあります。
