高速切断機で、まっすぐ(0°)なら切れたパイプが、45°に振ると切り落とせない。切っている途中で止まる、ブレーカーが落ちる。火花ばかり出て進まず、切り口が焼ける。この記事は、そうした場面で切断角度・砥石・電源のどこに原因があるのかを切り分け、必要なら機種を選び直すためのものです。

比較に使うのは、HiKOKI(工機ホールディングス)の公式サイトに載っている高速切断機2機種と、対比のための手持ちのチップソーカッタ1機種です。今回は同じメーカーの中での比較で、他社の機種は扱いません。HiKOKI の高速切断機の製品ページには、最大切断能力が 0° と 45° に分けて書かれていて、45° では公表値がはっきり小さくなります。

先に結論
  • 「まっすぐなら切れるのに、斜めだと切れない」は、まず公式の切断能力の範囲を疑う。CC12SF の丸パイプは 0° で ø102mm、45° では ø60mm と公表されている
  • 45° で太いパイプを切るなら 355mm 砥石の CC14SF。丸パイプは 0° で ø120mm、45° で ø100mm(公式)
  • 火花ばかりで進まない・焼けるなら、砥石の用途を確かめる。HiKOKI は別売の切断砥石を「ステンレス・金属の切断」と「軽天材・一般鋼材の切断」に分けている
  • 途中で止まる・ブレーカーが落ちるなら、電源を見る。両機とも 100V で 15.0A・1,450W。細く長い延長コードは避ける
  • 砥石が減ったときにどこまで切れるかは、公式の製品ページには書かれていない。この記事でも数値は書かない

切れない原因を切り分ける

「高速切断機で切れない」には、斜めにすると切り落とせない・刃が進まない・途中で止まる・使ううちに切り残しが出る、という場面が混ざっています。場面ごとに疑う所が違うので、先に分けます。

この記事の前半は「なぜ切れないか」に答えます。後半は、次に同じことが起きないように、材料の寸法と切断角度から機種をどう選ぶかを扱います。切断の手順や砥石の交換手順は扱いません。各製品の取扱説明書に従ってください。

斜めだと切り落とせない — 0° と 45° の最大切断能力

高速切断機は、材料をバイスで固定し、回転する砥石を上から下ろして切ります。材料を斜めに固定すると、砥石が通る断面はまっすぐ切るときより長くなるのが一般的な関係です。HiKOKI の仕様表は、この違いを 0° と 45° の最大切断能力として別々に公表しています。

差が大きいのは CC12SF の丸パイプです。0° の ø102mm に対して、45° では ø60mm と公表されています。たとえば外径 76mm ほどのパイプは、CC12SF でも 0° なら公表値の範囲ですが、45° では範囲を超えます。「まっすぐなら切れるのに、斜めだと切り落とせない」は、故障ではなく、公式の切断能力の範囲の話である可能性が高い、ということです。

CC14SF は、45° の丸パイプが ø100mm と公表されていて、CC12SF の 0° に近い値です。斜め切りで太いパイプを扱うことが多いなら、こちらが候補になります。なお、両機の仕様表には 0° と 45° の値だけが載っていて、その間の角度での切断能力は、公式の製品ページには記載が見当たりませんでした。

50A までなら手持ちも候補 — CD7SA との対比

据え置きの高速切断機を選び直す前に、材料の太さを見直す価値があります。手持ちのチップソーカッタ CD7SA は、最大切断能力が丸パイプ ø60.5mm(50A)、アングル 60×60mm と公表されていて、質量は 4.0kg です。CD7SA を含むチップソーカッターの切込み深さの考え方はチップソーカッターで切れない原因で詳しく比べたので、ここでは繰り返しません。

ただし、CD7SA の製品ページには斜め切りのときの切断能力は記載が見当たりませんでした。記載がないことは「斜めに切れない」と同じ意味ではありませんが、45° での能力を公表値で比べられるのは、今回の3機種のうち高速切断機の2機種だけです。

公表値から引ける線は次のとおりです。まっすぐ切る 50A(外径60.5mm)までなら、手持ちの CD7SA も候補。それより太いパイプや、45° の斜め切りが多いなら、45° の公表値が大きい CC14SFを見ます。据え置きでまっすぐ切る道具としてはバンドソーもあり、バンドソーで切断が曲がる原因で扱っています。

火花ばかりで進まない・焼ける — 砥石の種類

材料の寸法が範囲内なのに進まない、火花ばかり出て切り口が焼ける場合は、砥石を疑います。一般に、切断砥石は材料に合わせて種類が分かれていて、合わない砥石や強すぎる押し付けは、切れ味の低下や発熱につながるとされています。

ステンレスを切るなら「ステンレス・金属の切断」の砥石、軽天材や一般鋼材なら「軽天材・一般鋼材の切断」の砥石、というのがメーカーの分け方です。標準付属品は「トイシ(本体装着)」と書かれていますが、本体に付いている砥石がどちらの種類かは、公式の製品ページには記載が見当たりませんでした。切る材料が変わったら、付いている砥石の表示を確かめてください。

砥石を買うときは、外径と穴径(25.4mm)が機種に合うものを選びます。355mm と 305mm は別の機種用で、適用機種も分けて書かれています。もうひとつ見るのが最高使用周速度です。砥石には回転数(min-1)ではなく周速度(m/s)で上限が書かれることがあり、その単位のずれはディスクグラインダーの砥石の選び方で扱っています。

参考に、公表値から計算すると、外径 355mm の砥石を 3,800min-1(CC14SF)で回したときの周速度は約 70m/s、外径 305mm を 4,400min-1(CC12SF)で回したときも約 70m/s です(周速度 = 円周率 × 外径 × 回転数 ÷ 60 で当サイトが計算した値で、メーカーの公表値ではありません)。CC12SF の回転数が高いのは、砥石が小さいぶん、同じくらいの周速度にするためと読めます。

前は切れた太さで切り残しが出る — 砥石の摩耗

使ううちに、以前は切れた太さで切り残しが出るようになった場合は、砥石が減って外径が小さくなっていることを疑います。一般に、切断砥石は使うと外周から減っていき、外径が小さくなると材料に届く深さも小さくなるとされています。

ただし、砥石が減ったときに切断能力がどれだけ下がるかは、HiKOKI の製品ページには書かれていません。この記事でも、「何mm減ったら何mmまで」という数値は書きません。表の最大切断能力は、公式の仕様表の値です。砥石の交換の目安は取扱説明書で確かめてください。

途中で止まる・ブレーカーが落ちる — 15A 機と延長コード

CC14SF・CC12SF は、どちらも 100V で電流 15.0A・消費電力 1,450W と公表されています(CC14SF の200V仕様は 7.5A)。一般に、電流の大きい工具を細く長い延長コードにつなぐと電圧が下がり、パワーが出にくくなるとされています。また、同じ回路で他の機器も使っていると、ブレーカーの容量を超えることがあります。

延長コードの太さと長さの目安は、電動工具の延長コードは何mまで伸ばせるかで、取扱説明書が公表している表をもとに整理しています。コードリールを巻いたまま使うと使える電流が別に決まっている点は、コードリールの定格電流と限度電流を参照してください。本体のコードは CC14SF・CC12SF ともに 2心・4m(CC14SF の200V仕様は 2.3m)です。

途中で止まる原因は電源だけではありません。材料がバイスで確実に固定されていないと、切断中に動いて砥石が挟まれることがある、というのが一般的な説明です。両機ともバイス開きは 240mm で、ワンタッチバイスが付いています。回転工具のキックバックの起こり方と、それを抑える機能の考え方はグラインダーのキックバック対策でまとめています。

砥石の取替えと法令

研削といし(切断砥石を含む)には、労働安全衛生規則に条文があります。e-Gov 法令データで本文を確認できたものだけを挙げます。いずれも「事業者は」で始まる、事業者に対する定めです。

  • 第百十七条(研削といしの覆い):回転中の研削といしが労働者に危険を及ぼすおそれのあるときは、覆いを設けなければならない(直径が五十ミリメートル未満の研削といしを除く)
  • 第百十八条(研削といしの試運転):その日の作業を開始する前には一分間以上、研削といしを取り替えたときには三分間以上試運転をしなければならない
  • 第百十九条:研削といしについては、その最高使用周速度をこえて使用してはならない
  • 第百二十条:側面を使用することを目的とする研削といし以外の研削といしの側面を使用してはならない
  • 第三十六条第一号:特別教育を必要とする業務として「研削といしの取替え又は取替え時の試運転の業務」を挙げている

これらの条文が個々の作業や現場にどう適用されるかについて、当サイトは判断しません。職場で使う場合は、事業場の安全衛生の担当者や公的な窓口で確認してください。火花と切粉が飛ぶ作業なので、保護メガネが曇って見えにくい場合は保護メガネが曇る原因も参照してください。
