水中ポンプのスイッチを入れたのに、水が上がってこない。出るには出るが、ちょろちょろとしか出ない。水たまりの最後の数cmが吸えずに残る。泥水をくんでいたら途中で止まった。この記事は、そうした場面で水位・ホースの高さ・水の質・地域の周波数のどこに原因があるのかを切り分け、必要なら場面に合う機種を選び直すためのものです。

比較に使うのは、工進(KOSHIN)の公式サイトの「水用ポンプ」に載っている水中ポンプ4型です。同一メーカー内の比較で、メーカー横断の比較ではありません。工進は型番ごとの仕様表に「最低起動水位目安」「残水水位目安」「全揚程」「吐出量」「液質」「最大固形物サイズ」「定格周波数」を同じ書式で載せていて、「何cmの水位から動き出すか」「どこまで吸い切れるか」が型番でまったく違うことが、公式の表記だけでたどれるためです。当サイトがポンプを動かして確かめた記録ではありません。

先に結論
  • 動き出さないなら、水位を見る。工進の仕様表の最低起動水位目安は、YK-525 が 6cm、KS-20 が 8cm、フロート付きの PSK-53210A は 32-36cm(フロートの始動水位と同じ)
  • 最後の水が残るなら、残水水位を見る。YK-525 は 1cm、KS-20 は 2.4cm、PSK-53210A は 10-13cm(フロートの停止水位と同じ)
  • 少ししか出ないなら、ホースの先の高さを全揚程と比べる。全揚程は KS-20 が 50Hz 3.9m/60Hz 5m、PSK-53210A が 6.5m、YK-525 が 9.5m、充電式の SSP-1820 が 17.5m
  • 泥水で止まったなら、液質を見る。KS-20・YK-525・SSP-1820 は公式に「清水専用」。固形物10mmまでが仕様表にあるのは簡易汚物用の PSK-53210A
  • 50Hz専用・60Hz専用の機種は地域に合わせる。YK-525 と PSK-53210A は 50Hz、KS-20 は 50/60Hz兼用で、周波数によって全揚程の公表値が違う

「水が出ない」には、動き出さない・少ししか出ない・最後が吸えない・途中で止まったの4つの場面が混ざっています。場面ごとに疑う所が違うので、先に分けます。

動き出さない — 最低起動水位目安

水中ポンプは水に沈めて使う機械で、工進の仕様表には型番ごとに「最低起動水位目安」が載っています。言葉どおりに読めば、水位がこの目安より低いと動き出しにくい、という目安です。4型の公表値を並べると次のとおりです。

工進公式サイトの各製品ページの仕様表の記載です。PSK-53210A の2つの値には「フロートの始動/停止水位と同じです」と注記があります。

目立つのは PSK-53210A です。起動水位が 32-36cm、残水水位が 10-13cm で、これはフロートの始動・停止水位と同じと公式に注記されています。フロートスイッチ付きの機種は、水位が上がるとフロートが浮いて運転し、下がると止まる仕組みが一般的です。浅い水たまりにフロート付きの機種を入れても、水位が始動水位に届かなければ動き出さない、と読めます。故障を疑う前に、まず水深を測ってください。

SSP-1820 の最低起動水位目安は、数値ではなく「製品高さの1/3」と書かれています。仕様表のポンプの全高は 163mm なので、単純に3で割ると約5.4cmです。これは当サイトが割り算した値で、工進の公表値ではありません。

最後の水が吸えない — 残水水位目安

ポンプが動いていても、水位が下がると、ある高さで吸えなくなります。工進はこれを「残水水位目安」として載せています。清水用の YK-525 は 1cm、KS-20 は 2.4cm で、浅い水を最後まで吸い切りたい場面では、残水水位の低い清水用の側が公表値の上では有利です。KS-20 の特長欄にも「低水位でも使いやすい」とあります。

反対に、PSK-53210A は残水水位目安が 10-13cm です。フロートの停止水位と同じなので、水位がそこまで下がると止まると読めます。地下の湧水たまりのように、水位が上がったら排水して下がったら止まる、という使い方を前提にした機種です。公式の用途欄にも「ビル・工場・倉庫地下などの湧水たまり水の排水に」とあります。水たまりを底まで空にしたいのに 10cm前後が残る場合、ポンプの不調ではなく機種の想定と使い方が合っていない可能性があります。

SSP-1820 の残水水位目安は、仕様表の欄が空です。公式表記を確認できていないため記載しません。

少ししか出ない — 全揚程と吐出量

水は出るのに勢いが弱い、ちょろちょろとしか出ない場合は、ホースの先をどれだけ高く上げているかを疑います。工進の仕様表には「全揚程」と「吐出量」が並んでいます。

工進公式サイトの各製品ページの仕様表の記載です。

全揚程は、一般にポンプが水を押し上げられる高さの上限を表す値で、その高さに近づくほど出てくる水の量は減っていく、というのが一般的な説明です。吐出量は、高さをほとんど付けない条件での量と読むのが一般的です。つまり「全揚程 3.9m」の機種で 3m の高さまで送ると、公表の 40L/min は出ないと考えたほうが安全です。どれだけ減るかは型番ごとの性能曲線(工進の製品ページに PDF がある)で決まりますが、この記事では性能曲線を読んでいないため、数値は書きません。

4型を並べると、高く送るなら全揚程、量を出すなら吐出量で、両者は同じ向きに並びません。全揚程がいちばん高いのは充電式の SSP-1820(17.5m)ですが、吐出量は 30L/min でいちばん少なく、吐出量がいちばん多い PSK-53210A(150L/min)は全揚程 6.5m です。2階のベランダへ送りたいのか、地下の水を早く抜きたいのかで、見る数字が変わります。

ホースは、高さだけでなく長さと細さでも水の出が落ちるのが一般的です。吐出口径は 20mm・25mm・32mm と型番で違い、付属のタケノコニップルでホース径に合わせる形です。水中ポンプのホースは、高圧洗浄機の高圧ホースとは別物です。高圧洗浄機で「圧力」と「水量」の数字を読み分ける話は高圧洗浄機で汚れが落ちない原因で扱っています。

泥水で止まった — 液質と最大固形物サイズ

工進は液質を仕様表に書いたうえで、備考で定義しています。清水用の KS-20・YK-525・SSP-1820 の備考は「このポンプは【清水専用】です。それ以外の液体を使用した場合には保証対象外となります。」で、清水を「水道水、濁りのない井戸水・農業用水」と定義しています。SSP-1820 にはさらに、使用不可の例として海水・汚水・農薬・消毒液・灯油・有機溶剤などが挙がっています。

簡易汚物用の PSK-53210A は、液質が「清水、簡易汚水、簡易汚物」、最大固形物サイズが 10mm です。備考では、簡易汚水を「濁りのある水」、簡易汚物を「10㎜以下の固形物(やわらかいもの)を含んだ、水分90%以上の水」と定義しています。同じ備考には「土砂・スラリーの混じった水に使用すると、ポンプ寿命が著しく短くなります」、用途欄には「石などの硬い固形物を含む水に使用した場合、インペラの磨耗が早くなります」とあります。

まとめると、清水専用の機種で泥水やごみの混じった水を吸っているなら、詰まりや停止の前に、そもそも公式の液質の範囲を外れています。泥水・落ち葉の混じった水を扱うなら簡易汚物用の側ですが、簡易汚物用でも硬い固形物や土砂は寿命を縮めると公式が注意しています。吸込口の詰まりの取り方は、各製品の取扱説明書の手順に従ってください。

地域の周波数 — 50Hz専用と60Hz専用

工進の水中ポンプには、50Hz専用・60Hz専用・兼用の機種があります。仕様表の「定格周波数」は、YK-525 と PSK-53210A が 50Hz、KS-20 が 50/60Hz です。PSK-53210A には60Hz用の PSK-63210A が別品番であり、公式の仕様表では全揚程 8m・吐出量 140L/min・定格周波数 60Hz と、50Hz用とは値が違います。

兼用の KS-20 も、全揚程の公表値は 50Hz で 3.9m、60Hz で 5m と、周波数で変わります。同じ型番でも、使う地域の周波数で公表値が違うということです。専用機を地域と違う周波数で使ったときに何が起きるかは、公式の製品ページでは確認できていないので書きません。買う前に、使う場所の電源が 50Hz か 60Hz かを確かめ、専用機ならその周波数の品番を選んでください。

電源まわり — 延長コード・発電機・漏電

水中ポンプは水の中で電気を使う機械なので、電源まわりは取扱説明書の指示がすべてです。ここでは公式の仕様表に載っている事実だけを並べます。

  • 電源コードの長さ: KS-20 は 3m、YK-525 は 4m、PSK-53210A は 4.3m(公式の仕様表)
  • 漏電遮断器: KS-20 は仕様表に「3m(漏電遮断器付)」、特長欄に「漏電遮断器付きコードが標準装備」とある。ほかの3型の製品ページでは、漏電遮断器についての記載は見当たらなかった。記載が見当たらないことは「付いていない」と同じ意味ではないので、各製品の取扱説明書で確認してください
  • SSP-1820 の充電器: 備考に「昇圧器などのトランス類を使用したり、直流電源やエンジン発電機では使用しないでください。発熱・火災のおそれがあります。」とある

感電・漏電への備えや、屋外コンセント・接地(アース)の扱いは、ポンプの機種だけでは決まらず、設備の側の話になります。この記事では一般論以上のことは書きません。設備側に不安があるときは、電気工事の専門家に相談してください。

コードが届かずに延長する場合、延長コードの太さと長さで使える電流が変わります。その考え方は電動工具の延長コードは何mまで伸ばせるか、コードリールを巻いたまま使うときの定格の下がり方はコードリールの定格電流と限度電流で扱っています。発電機から AC機を動かす場合の定格出力の読み方は発電機で電動工具が動かない原因を参照してください。なお、電動工具の「防水」等級は水没を前提にしていないことを電動工具の「防水」は等級で書かれているで整理しています。水に沈めて使う水中ポンプとは前提が違う、という点だけ押さえておけば十分です。

買う前の確認手順

この順で確認する
  • 水深を測る。くみたい水の深さが、仕様表の最低起動水位目安(フロート付きならフロートの始動水位)を超えているか
  • どこまで吸い切りたいかを決める。底近くまで空にしたいなら、残水水位目安の低い機種
  • 送る高さを測る。水面からホースの出口までの高さが、全揚程に対して十分に低いか。量が要るなら吐出量も見る

  • 地域の周波数を確かめる。50Hz専用・60Hz専用なら、使う場所に合う品番を選ぶ
  • 電源を確かめる。コードの長さ、延長の要否、漏電への備えを取扱説明書で確認する
