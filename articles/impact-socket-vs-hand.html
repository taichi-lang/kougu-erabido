インパクトレンチを買うと、次に迷うのがソケットです。「手持ちのソケットセットをそのまま使えないのか」という疑問は、ほぼ全員が通ります。

検索して出てくる説明は、たいてい「インパクト用は黒くて、材質がねばい」「肉厚が違う」で終わります。間違いではありませんが、それは結果の話です。

もっと手前に、規格そのものの線引きがあります。ソケットレンチのJIS規格は、適用範囲を「手動式」と明記しています。この記事は、その一文から出発して、何が規格で保証されていて何が保証されていないのかを整理する記事です。

先に結論
  • JIS B 4636-2 の適用範囲は「手動式ソケットレンチ」です。電動インパクト工具で使うソケットは、この規格が規定している対象ではありません
  • 対応する国際規格の題名にも "Hand-operated"(手動式)と入っています。訳語の問題ではなく、元の規格からそう区切られています
  • 規格には「最小試験トルク」が定められています。6.3角ドライブのソケットの最小試験トルクは、規格の表の中で最大でも68.6 N·mです
  • 一方、マキタが公表するインパクトドライバー TD173D の締め付けトルクは最大180 N·mです。桁が違う話ではありませんが、明らかに上回ります
  • だから「インパクト用」という表示は、規格適合の表示ではなく、メーカーの適合表示です。選ぶ基準は、規格記号ではなくメーカーの公表内容になります

規格の適用範囲に、はっきり「手動式」と書いてある

JIS B 4636-2:1998「ソケットレンチ−6.3〜25角ドライブ」の適用範囲は、次の一文です。

「この規格は，六角ボルト・ナットの組付け又はその取外しに用いる，手動式ソケットレンチについて規定する。」

ここで区切られているのは材質でも硬さでもなく、駆動の方法です。手で回すものについて規定する、と書かれています。

これは日本語訳の都合ではありません。同じ規格が挙げている対応国際規格の題名を見ると、同じ線引きが元からあることが分かります。

対応国際規格題名(該当部分)
ISO 1174-1 : 1996Driving squares−Part 1 : Driving squares for hand socket tools
ISO 1711-1 : 1996Technical specifications−Part 1 : Hand-operated wrenches and sockets
ISO 2725-1 : 1996Square drive sockets−Part 1 : Hand-operated sockets−Dimensions
ISO 3315 : 1996Driving parts for hand-operated square drive socket wrenches
ISO 3316 : 1996Attachments for hand-operated square drive socket wrenches

寸法も、試験も、材質も、すべて「手で回す前提」で書かれた体系だということです。電動インパクト用のソケットは、この体系の中に規定が置かれていません。

「規格の対象外」は「粗悪」という意味ではない

ここは誤解されやすいので、はっきり書きます。規格の対象外であることは、品質が低いという意味ではありません。

インパクト用ソケットは、打撃を受ける前提で作られた別の製品です。規格が無いということは、「良し悪しの共通のものさしが公的に定義されていない」ということであって、製品として劣るという話ではありません。

実務上の意味は一つだけです。「JIS適合」という言葉で選べない。だから、メーカーが自分で公表している適合内容(対応する工具、差込角、用途)を読むしかありません。

規格が保証しているトルクの水準を、実際に見てみる

手動用ソケットの側には、規格に「最小試験トルク」が定められています。ソケットの呼び(二面幅)と差込角ごとに数値が並んでいます。JIS B 4636-2 から、6.3角ドライブと10角ドライブの一部を引きます。

並べると構図が見えます。6.3角ドライブの手動用ソケットに規格が求めている最小試験トルクは、表の最大でも68.6 N·mです。一方、6.35mm六角軸のインパクトドライバーが公表しているのは最大180 N·mです。

ここで注意が要ります。最小試験トルクは「これ以上で壊れる」という値ではありません。規格が最低限これに耐えることを求めている、という下限値です。ですから「68.6を超えたら割れる」と読むのは誤りです。

正しく読めるのは次の一点だけです。手動用ソケットに公的に要求されている強さの水準は、電動インパクト工具が公表している出力の水準を前提にしていない。それだけのことですが、選ぶ理由としては十分です。

もう一つの数字 — ソケットは「手で抜ける」ように作られている

見落とされやすい規定があります。JIS B 4636-2 には「ソケットとハンドル類の分離力」という表があり、「接続したソケットとハンドル類は，表10の分離力以下の荷重で外れてはならない」と規定されています。

角ドライブ分離力
6.3角4 N
10角11 N
12.5角25 N
20角45 N
25角45 N

6.3角で4Nです。これは「この程度の力では外れてはいけない」という下限であって、それ以上の力を加えれば抜ける設計だということでもあります。手で抜き差しして使うものだからです。

インパクト用の差込部にピン穴やOリングによる抜け止めがある製品が多いのは、この前提が変わるためです。回転と打撃が加わり続ける使い方は、手動式の想定の外にあります。

「インパクト用」と書いてあっても、差込角が合わなければ付かない

もう一段、購入直前に効く話があります。「インパクト用ソケット」と表示されていても、取付部の形が2種類あります。

取付部の2種類
  • 四角い角ドライブ … インパクトレンチ側。JIS B 4636-2 の凸角ドライブの二面幅は、6.3角=6.35mm / 10角=9.53mm / 12.5角=12.70mm / 20角=19.05mm / 25角=25.40mm
  • 六角軸6.35mm … インパクトドライバー側。ビットと同じ取付部で、断面が六角です

6.35mmという数字は両方に出てきますが、片方は四角、片方は六角です。数字が同じでも入りません。インパクトドライバーで使うソケットは、六角軸のシャンクにソケットが付いた「ソケットビット」の形になっているのが普通で、これは角ドライブのソケットとは別の製品です。

この六角軸6.35mmという取付規格が何を先に決めてしまうのかは、インパクトドライバーで穴あけはできるかで扱いました。ソケット側のサイズ(二面幅)そのものの決まり方はソケットのサイズは「M10だから17mm」では決まらないにまとめています。

買う前に確認する順序

この順で確認する
  • ① 自分の工具の取付部が、四角(角ドライブ)か六角軸6.35mmかを確定させる。取扱説明書の主要機能に記載があります
  • ② 四角なら、その呼び(6.3 / 9.5 / 12.7 / 19.0 など)を確認する。カタログの12.7と12.5は同じものです
  • ③ 「インパクト用」と明記された製品を選ぶ。手動用ソケットのJISは、電動での使用を想定して書かれていません
  • ④ 抜け止め(ピン穴・Oリング・ボール)の方式が、自分の工具側と合うかを見る。ここが合わないと固定できません
  • ⑤ 回したいボルトの二面幅を実測してから呼びを決める。呼び径からの逆引きは系列によって外れます

工具本体を選ぶ段階の話は18Vインパクトドライバー比較とネジ締め能力の読み方に、トルクという単位そのものの読み方はトルク(N·m)の読み方にあります。

ここで見た「JIS B 4636-2 の適用範囲は手動式」という線引きは、差込角を変換するアダプタにもそのまま当てはまります。アダプタ側の規格の表は差込角の変換アダプタは「向き」で別の製品にまとめました。

手動側でトルクを管理する道具については、トルクレンチは最大値の20%未満では規格の対象外で、規格の許容差とメーカーの公称精度が別の数字であることを扱っています。

ソケットが回している相手の側の規格は、ボルトの締付けトルクとJIS規格にまとめました。強度区分の規格は、トルクを規定項目から明文で外しています。

手動側の工具に規格が定めている口の許容差と試験トルクはスパナの二面幅と等級N・H(JIS B 4630)、回す相手のナットは六角ナットの種類と厚さ(JIS B 1181)です。
