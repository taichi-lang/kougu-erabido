棚や手すりを付けたいのに、下地センサーを壁に当てても鳴らない。間柱があるはずの場所で反応しない。この記事は、そうした場面で壁の厚さ・壁の材質・モードの選び方・電池のどこに原因があるのかを切り分け、必要なら機種を選び直すためのものです。

比較に使うのは、シンワ測定の公式サイトに載っている電子式の下地センサー4機種(Home・Basic・Pro・Pro+)と、針で刺して確かめる「下地探し どこ太」2機種です。同一メーカー内の比較で、メーカー横断の比較ではありません。シンワ測定は製品ページごとに「探知物検出深度」「探知可能条件」「電線探知深度」を同じ書式で載せていて、「どの深さまで届くか」「どの壁材で使えるか」が機種でどう違うかを、公式の表記だけでたどれるためです。当サイトがセンサーを壁に当てて確かめた記録ではありません。

先に結論
  • 厚い壁で鳴らないなら、検出深度を見る。4機種とも通常モードは約19mm。深部モード(約35mm)があるのは Basic・Pro・Pro+ で、入門機の Home には深部モードの記載がない
  • 壁材を見る。公式の探知可能条件は「ベニヤ、石膏ボード、強化石膏ボード(種類によっては使えないものがあります。)」。これ以外の壁材は公式の条件の外
  • 木と金属は分けられない。通常・深部モードでは4機種とも木材と金属を判別できない(公式)。金属を別に探すモードがあるのは Pro+ だけ
  • 買ったばかりで鳴らないなら、電池を疑う。4機種とも9V電池1本で、公式に「付属の電池はモニター用の為、寿命が短い場合があります」とある
  • センサーで決めきれないなら、針で確かめる。どこ太は針で刺して木製下地を探す石膏ボード用の針式で、探知可能壁厚は Basic 25mm・Pro 35mm

反応しない原因を切り分ける

「反応しない」には、どこに当てても鳴らない・ある壁だけ鳴らない・鳴るけれど下地なのか分からない、の場面が混ざっています。場面ごとに疑う所が違うので、先に分けます。

症状疑う項目確かめること
買ったばかりなのに、どこに当てても反応しない・すぐ反応しなくなった付属電池の消耗・電池フィルム9V電池の残量。公式は「付属の電池はモニター用」「ご購入時は電池フィルムを剥がしてから」と注記
ほかの壁では反応するのに、この壁だけ鳴らない壁が厚く、検出深度を超えている機種の探知物検出深度(通常 約19mm/深部 約35mm)と、深部モードに切り替えたか
そもそも壁の材質が分からない・ボードではなさそう壁材が公式の探知可能条件の外ベニヤ・石膏ボード・強化石膏ボードか。強化石膏ボードでも「種類によっては使えないもの」がある
反応はするが、木の間柱なのか金属なのか分からない通常・深部モードでは判別できない仕様公式の探知可能条件の括弧書き「木材と金属の判別はできません」。Pro+ には金属モードがある

この記事の前半は「なぜ反応しないか」に答えます。後半は、壁の厚さと材質から機種をどう選び直すかを扱います。センサーが壊れているかどうかの判断は扱いません。異常があるときは、各製品の取扱説明書とメーカーの窓口に従ってください。

下地センサーは何を検知しているか

シンワ測定の公式Q&Aは、下地センサーの仕組みを、内部の電極の間に「壁より密度の高い物体が入った時の静電容量の変化」を検知して、光やブザー音で知らせるもの、と説明しています。つまり壁の裏にある「壁より密度の高い物」の変化を拾っているのであって、木の間柱だけを狙って見分けているわけではありません。

この説明から、次の2つが読み取れます。

  • 届く深さには上限がある。それが製品ページの「探知物検出深度」です
  • 何が入っているかは区別しにくい。製品ページの探知可能条件に「木材と金属の判別はできません」と書かれているのは、この仕組みの裏返しと読めます

なお、下地が壁の裏から離れている場合や、壁の裏に断熱材などがある場合にどう反応するかは、公式Q&Aでは確認できていないため書きません。

厚い壁で鳴らない — 探知物検出深度と深部モード

4機種の探知物検出深度を並べると、次のとおりです。

目立つのは、通常モードの約19mmは4機種で同じという点です。上位機に替えても、通常モードのままなら届く深さは変わりません。Basic・Pro・Pro+ の特長欄には「壁の材質や厚さによって検出深度を切り替えられます」とあり、厚い壁では深部モードに切り替えることが前提になっています。

反対に、Home の製品ページには深部モードの記載がありません。壁の厚さが約19mmを超えていると、Home では届かない可能性がある、と読めます。ボードが二重に張られている壁などでは厚さが増えますが、何mmになるかは壁ごとに違い、当サイトでは一次情報で確認できていないため、数値は書きません。手持ちの機種がどの深さまで届くかを、まず製品ページで確かめてください。

Pro+ の金属モードは、製品ページに「壁材毎に異なる」とあり、鉄と鉄以外の金属で値が分かれて並んでいます。ただ、どの壁材がどの値に当たるかを公式ページのテキストから読み取れなかったため、この記事では内訳を書きません。購入前に製品ページか取扱説明書で確認してください。

壁材が違う — 探知可能条件

4機種とも、探知可能条件はおおむね同じ書き方です。Home と Basic は次のとおりです。

「壁材がベニヤ、石膏ボード、強化石膏ボード(種類によっては使えないものがあります。)の時に木材と金属を探知可能(木材と金属の判別はできません。)」

Pro と Pro+ も、並び順が違うだけで、壁材はベニヤ・強化石膏ボード・石膏ボードの3つです。Pro+ は「通常モード・深部モードで」と前置きがあり、括弧書きが「木材や金属、プラスチックの判別はできません。」になっています。

ここから読めるのは2点です。

  • 公式の探知可能条件に挙がっている壁材は、ベニヤ・石膏ボード・強化石膏ボードの3つだけ。それ以外の壁材で使えるかどうかは、製品ページでは確認できません
  • 強化石膏ボードでも「種類によっては使えないもの」がある。どの種類が使えないかは製品ページに書かれていないため、この記事では挙げません

コンクリートの壁に物を固定する場合は、そもそも下地を探す話ではなく、アンカーで固定する話になります。アンカーの下穴径をどう決めるかはあと施工アンカーの下穴径は自分で決めないで扱っています。

鳴るけれど分からない — 木と金属は判別できない

公式の探知可能条件の括弧書きにあるとおり、通常・深部モードでは、4機種とも木材と金属を判別できません。反応した場所が木の間柱なのか、金属の下地なのか、それ以外の物なのかは、センサーの反応だけでは決まらない、ということです。

Pro と Pro+ の特長欄には「間柱の端を探知すると表示とブザー音でお知らせします」「間柱の中心を一発探知できます」とあります。位置を絞り込む機能は上位機にありますが、何があるかを判別する機能ではない点は、Home・Basic と同じです。金属を別に探す「金属モード」があるのは、4機種のうち Pro+ だけです。

壁の下地が木か鋼製(軽天)かで、使うビスやドライバーも変わります。下地の種類とボード用ドライバーの関係はボードビスが沈みすぎる・浮く原因で整理しています。

電線探知 — 通電中の交流電流を察知する機能

Basic・Pro・Pro+ には「電線警告機能」があり、特長欄には、Basic が「通電中の交流電流を察知すると電線警告ランプが点灯します」、Pro・Pro+ が同じく液晶の電線警告マークが点灯する、と書かれています。電線探知深度は3機種とも約30mmで、「壁材の乾燥具合、壁材から電線の間にある障害物の有無によって数値は変動します」と注記されています。Home の製品ページには電線探知の記載がありません。

公式の説明は「通電中の交流電流」を察知する、というものです。通電していない電線や、条件によって反応しない電線があり得るかどうかは、製品ページでは確認できていないため、この記事では断定しません。警告が出なかったことを「電線が無い」の根拠にしない、というのが安全側の考え方です。

壁の中の配線に関わる作業は、電気工事士の資格が要る作業に当たるかどうかが問題になる場面があります。どこからが資格の要る作業かは、この記事では判断しません。不安があるときは、電気工事の専門家に相談してください。電気が来ているかを確かめる道具の側の話は検電器が反応しない原因で扱っています。

買ったばかりで鳴らない — 付属電池と電池フィルム

4機種とも電源は9Vアルカリ乾電池1本で、製品ページに次の2つの注記があります。

  • 「付属の電池はモニター用の為、寿命が短い場合があります。」
  • 「ご購入時は電池フィルムを剥がしてからご使用ください。」

買ったばかりなのにどこに当てても反応しない、少し使っただけで反応しなくなった、という場合は、故障を疑う前に電池フィルムと電池の残量を確かめてください。電池が弱ったときに本体がどう表示するかは製品ページでは確認できていないため、取扱説明書に従ってください。Home と Basic の製品ページには、ブザー音に「探知した時の音」と「探知できなかった時の音(エラー音)」がある、とも書かれています。

センサーで決めきれないとき — 針で刺す「どこ太」

センサーの反応だけでは位置を決めきれないときの次の手として、シンワ測定は針で刺して確かめる「下地探し どこ太」を出しています。公式の特長欄は「石膏ボード用の針式の下地探しです」「ボード裏の木製下地を針で刺して探知します」で、刺して針が止まる所に木製下地がある、という確かめ方です。
