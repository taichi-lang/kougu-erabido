## 全体の注意（3本共通）

- **マキタの製品ページ（`/product/detail/?model=...`）は仕様表を JavaScript で描画する。**
  WebFetch では数値が取れない。**ブラウザで開き、約3秒待ってから最後の `table` の innerText を読む。**
  同一オリジンなら、1ページ開いたあと `iframe` で他機種を順に読み込んでも取れる（2026-10-03 はこの方法で全機種取得）。
- **HiKOKI の製品ページは WebFetch だと 404/403 になることがある**（URL の推測が外れるため。例: コンプレッサは `air/ec1245h3_ctn/` で、`air/ec1245h3/` は 404）。
  `curl -A "Mozilla/5.0"` で取得でき、下に書いた URL は 2026-10-03 に仕様表まで取得済み。
  カテゴリ一覧（例 `/products/powertools/air/air.html`）から製品 URL を拾うのが確実。
- マックスの製品ページは WebFetch で仕様表が取れる。
- **「公式ページに記載が無い」は「その機能が無い」ではない。** 本文では「公式の製品ページには記載が見当たらない」と書く。執筆時に公式ページを開き直して確認する。
- **体験を装わない。** 原因の説明は一般論＋公式の公表値まで。
- 価格は未調査（公式ページに標準小売価格が出ているものはあるが、実売ではない）。`price_note` に調査時点を書く通常手順で。
- 検索上位は WebSearch（米国経由）で見ただけ。**Search Console は未登録で、表示回数は見ていない。**
