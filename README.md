# 工具えらび堂

規格とメーカー公式スペックで選ぶ、誠実な工具選定ガイド。

**サイト**: https://kougu-erabido.vercel.app

## 特徴

- **実機レビューを装わない編集方針** — すべての記事はメーカー公式スペック・規格という一次情報に基づき、体験を装う表現(「使ってみた」等)を使わない
- **並び替え可能な比較テーブル** — 価格/特徴/メーカーの3軸でソート(昇順・降順)
- **ステマ規制対応** — 広告枠は「PR」ラベルを明示。広告データ(`ads.json`)が空のときは枠自体を描画しない(偽リンク・準備中枠を作らない設計)

## 技術スタック

- 自作の静的サイトジェネレーター(Python、依存ライブラリゼロ)
- フロントエンド: 素のHTML/CSS/JS(ビルド成果物は `dist/`)
- ホスティング: Vercel

## 開発

```bash
# ビルド
python build.py

# ローカル確認
python -m http.server 8890 --directory dist
```

## 記事の追加

`articles/<slug>.html` を作成する。先頭に `<!--META {json} META-->` ブロック(タイトル・説明・日付・カテゴリ・商品データ)、続けて本文HTMLを書く。`{{PRODUCT_TABLE}}` と書いた位置に、METAの `products` から並び替え対応の比較テーブルが生成される。

## 広告(PR枠)の追加

`ads.json` の `home_top` / `article_top` に `{"label": "...", "url": "..."}` を追加すると、各ページ上部に「PR」ラベル付きの枠が描画される。URLが空のエントリは描画されない。
